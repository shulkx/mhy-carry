# v0.3 直播间抢码（M6）实施计划

> **给执行者：** 在当前会话里按顺序执行（executing-plans），不要每个任务开一个子代理。步骤用复选框（`- [ ]`）跟踪。

**目标：** 直接拉 B 站直播流，识别到原神登录码就登录；自动确认改成用户开关，四种画面来源都能开。发布 v0.3.0（设计文档第 6.5 节、第 13 节 M6）。

**做法：**
- `core`：
  - 新增直播间解析、FLV 拆包、解码器接口和追帧规则；
  - 扫码会话加上直播的状态，直播间不超时；
  - 去掉“指定窗口、显示器永不自动确认”的硬性规则，加 `AlwaysAutoConfirm`。
- `platform`：用 Windows Media Foundation 的 H.264 解码器实现解码接口。
- 新 crate `live`：直播客户端（不带凭证）、B 站取流、直播画面来源 `LiveSource`。
- `runner`：按开关选确认策略；直播来源不限帧率；自动确认时预热连接。
- 命令行和应用接上这些。

**技术栈：** 不新增第三方依赖。windows crate 多开 `Win32_Media_MediaFoundation`、`Win32_System_Com` 两个功能。

**依据：** 设计文档 [docs/design/2026-10-11-mhy-carry-design.md](../design/2026-10-11-mhy-carry-design.md) 第 6.5 节；实验代码 `spikes/live-bench`（第 14 节第 9 项）。

//! 直播间（设计文档第 6.5 节）：解析你输入的直播间网址或房间号。以后加抖音就加一种直播间。

use std::fmt;

use url::Url;

/// 一个直播间。
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum LiveRoom {
    /// B 站直播间。`id` 是你输入的房间号，可能是短号，取流时会换成真实房间号。
    Bilibili { id: u64 },
}

impl fmt::Display for LiveRoom {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        match self {
            LiveRoom::Bilibili { id } => write!(f, "B 站直播间 {id}"),
        }
    }
}

#[derive(Debug, Clone, PartialEq, Eq, thiserror::Error)]
pub enum RoomError {
    #[error("请输入直播间网址或房间号")]
    Empty,
    #[error("暂不支持短链接，请在浏览器里打开后，复制地址栏里的网址")]
    ShortLink,
    #[error("认不出这个直播间，请输入 B 站直播间网址（比如 https://live.bilibili.com/12345）或房间号")]
    Unrecognized,
}

/// 解析直播间网址或房间号。纯数字按 B 站房间号处理；网址可以省略 `https://`。
pub fn parse_room(input: &str) -> Result<LiveRoom, RoomError> {
    let input = input.trim();
    if input.is_empty() {
        return Err(RoomError::Empty);
    }
    if is_number(input) {
        return bilibili(input);
    }
    let url = if input.contains("://") {
        Url::parse(input)
    } else {
        Url::parse(&format!("https://{input}"))
    }
    .map_err(|_| RoomError::Unrecognized)?;
    if !matches!(url.scheme(), "http" | "https") {
        return Err(RoomError::Unrecognized);
    }
    match url.host_str() {
        Some("b23.tv") => Err(RoomError::ShortLink),
        // 路径里第一个纯数字的段就是房间号：/12345、/h5/12345、/blanc/12345。
        Some("live.bilibili.com") => url
            .path_segments()
            .into_iter()
            .flatten()
            .find(|segment| is_number(segment))
            .map_or(Err(RoomError::Unrecognized), bilibili),
        _ => Err(RoomError::Unrecognized),
    }
}

fn is_number(text: &str) -> bool {
    !text.is_empty() && text.bytes().all(|b| b.is_ascii_digit())
}

fn bilibili(digits: &str) -> Result<LiveRoom, RoomError> {
    match digits.parse::<u64>() {
        Ok(id) if id > 0 => Ok(LiveRoom::Bilibili { id }),
        _ => Err(RoomError::Unrecognized),
    }
}

//! FLV 拆包（设计文档第 6.5 节）：从直播流里取出 H.264 视频帧，转成解码器要的 Annex B 格式。
//! 边收边拆：每收到一块数据就 `push` 进来，取出已经完整的帧；不完整的部分留到下次。

/// 一帧 H.264 视频，Annex B 格式：每个 NAL 前面是起始码 `00 00 00 01`。
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct VideoFrame {
    pub annexb: Vec<u8>,
    /// 关键帧。前面已经补上 SPS/PPS，可以从这一帧开始解码。
    pub key: bool,
    /// FLV 时间戳，毫秒。
    pub timestamp_ms: u32,
}

#[derive(Debug, Clone, PartialEq, Eq, thiserror::Error)]
pub enum FlvError {
    #[error("直播流不是 FLV 格式")]
    NotFlv,
    #[error("直播流不是 H.264")]
    NotH264,
    #[error("直播流的 H.264 配置不对")]
    BadConfig,
}

const START_CODE: [u8; 4] = [0, 0, 0, 1];
/// 标签头：类型 1 字节、数据长度 3 字节、时间戳 3+1 字节、流 ID 3 字节。
const TAG_HEADER: usize = 11;
/// 标签后面跟 4 字节的 PreviousTagSize。
const TAG_TRAILER: usize = 4;
const TAG_VIDEO: u8 = 9;
const MAX_HEADER: usize = 1024;
const CODEC_AVC: u8 = 7;
const FRAME_KEY: u8 = 1;

#[derive(Debug, Default)]
pub struct FlvParser {
    buffer: Vec<u8>,
    header_read: bool,
    avc: Avc,
}

/// 从 H.264 配置里读到的东西。
#[derive(Debug, Default)]
struct Avc {
    /// NAL 长度前缀占几个字节。0 表示还没收到配置。
    nal_length_size: usize,
    /// Annex B 格式的 SPS 和 PPS，关键帧前要补上。
    parameter_sets: Vec<u8>,
}

impl FlvParser {
    pub fn new() -> Self {
        Self::default()
    }

    /// 收到一块数据，返回已经完整的视频帧。音频和脚本标签直接跳过；
    /// 还没收到 H.264 配置之前的视频帧也跳过，因为解不了。
    pub fn push(&mut self, bytes: &[u8]) -> Result<Vec<VideoFrame>, FlvError> {
        self.buffer.extend_from_slice(bytes);
        let mut frames = Vec::new();
        let mut pos = 0;
        if !self.header_read {
            // 文件头：“FLV”、版本、标志、头长度（4 字节），后面跟 4 字节的 PreviousTagSize0。
            if self.buffer.len() >= 3 && &self.buffer[..3] != b"FLV" {
                return Err(FlvError::NotFlv);
            }
            if self.buffer.len() < 9 {
                return Ok(frames);
            }
            let header_len =
                u32::from_be_bytes([self.buffer[5], self.buffer[6], self.buffer[7], self.buffer[8]])
                    as usize;
            // 文件头正常是 9 字节。长得离谱就不是 FLV，免得一直攒数据等它。
            if !(9..=MAX_HEADER).contains(&header_len) {
                return Err(FlvError::NotFlv);
            }
            if self.buffer.len() < header_len + TAG_TRAILER {
                return Ok(frames);
            }
            pos = header_len + TAG_TRAILER;
            self.header_read = true;
        }
        while self.buffer.len() >= pos + TAG_HEADER {
            let tag = &self.buffer[pos..];
            let size = u32::from_be_bytes([0, tag[1], tag[2], tag[3]]) as usize;
            let end = pos + TAG_HEADER + size + TAG_TRAILER;
            if self.buffer.len() < end {
                break;
            }
            // 时间戳：低 24 位在前，第 4 个字节是最高 8 位。
            let timestamp_ms = u32::from_be_bytes([tag[7], tag[4], tag[5], tag[6]]);
            if tag[0] & 0x1f == TAG_VIDEO {
                let body = &self.buffer[pos + TAG_HEADER..pos + TAG_HEADER + size];
                if let Some(frame) = self.avc.video_tag(body, timestamp_ms)? {
                    frames.push(frame);
                }
            }
            pos = end;
        }
        self.buffer.drain(..pos);
        Ok(frames)
    }
}

impl Avc {
    fn video_tag(
        &mut self,
        body: &[u8],
        timestamp_ms: u32,
    ) -> Result<Option<VideoFrame>, FlvError> {
        let Some(&first) = body.first() else {
            return Ok(None);
        };
        // 增强 FLV（H.265 等）把最高位置 1；传统 FLV 的低 4 位是编码 ID，7 是 H.264。
        if first & 0x80 != 0 || first & 0x0f != CODEC_AVC {
            return Err(FlvError::NotH264);
        }
        // 第 2 个字节是包的类型，后面 3 个字节是合成时间偏移，用不上。
        if body.len() < 5 {
            return Ok(None);
        }
        match body[1] {
            0 => {
                self.read_config(&body[5..])?;
                Ok(None)
            }
            1 => Ok(self.read_nalus(&body[5..], first >> 4 == FRAME_KEY, timestamp_ms)),
            // 2 是序列结束。
            _ => Ok(None),
        }
    }

    /// 读 AVCDecoderConfigurationRecord：NAL 长度前缀的字节数、SPS 和 PPS。
    fn read_config(&mut self, record: &[u8]) -> Result<(), FlvError> {
        if record.len() < 6 {
            return Err(FlvError::BadConfig);
        }
        let mut sets = Vec::new();
        let mut pos = 6;
        for _ in 0..(record[5] & 0x1f) {
            pos = copy_parameter_set(record, pos, &mut sets)?;
        }
        let pps_count = *record.get(pos).ok_or(FlvError::BadConfig)?;
        pos += 1;
        for _ in 0..pps_count {
            pos = copy_parameter_set(record, pos, &mut sets)?;
        }
        self.nal_length_size = (record[4] & 0x03) as usize + 1;
        self.parameter_sets = sets;
        Ok(())
    }

    /// 把“长度 + NAL”的序列改写成“起始码 + NAL”。关键帧前补上 SPS/PPS。
    fn read_nalus(&self, data: &[u8], key: bool, timestamp_ms: u32) -> Option<VideoFrame> {
        if self.nal_length_size == 0 {
            return None;
        }
        let mut annexb = Vec::with_capacity(data.len() + self.parameter_sets.len() + 16);
        if key {
            annexb.extend_from_slice(&self.parameter_sets);
        }
        let mut pos = 0;
        while pos + self.nal_length_size <= data.len() {
            let len = data[pos..pos + self.nal_length_size]
                .iter()
                .fold(0usize, |n, byte| (n << 8) | *byte as usize);
            pos += self.nal_length_size;
            let Some(nal) = data.get(pos..pos.saturating_add(len)) else {
                break;
            };
            annexb.extend_from_slice(&START_CODE);
            annexb.extend_from_slice(nal);
            pos += len;
        }
        Some(VideoFrame {
            annexb,
            key,
            timestamp_ms,
        })
    }
}

/// 复制一个“2 字节长度 + 内容”的参数集，前面加起始码。返回下一个参数集的位置。
fn copy_parameter_set(record: &[u8], pos: usize, out: &mut Vec<u8>) -> Result<usize, FlvError> {
    let len = record.get(pos..pos + 2).ok_or(FlvError::BadConfig)?;
    let len = u16::from_be_bytes([len[0], len[1]]) as usize;
    let set = record
        .get(pos + 2..pos + 2 + len)
        .ok_or(FlvError::BadConfig)?;
    out.extend_from_slice(&START_CODE);
    out.extend_from_slice(set);
    Ok(pos + 2 + len)
}

//! 直播画面的解码接口和追帧规则（设计文档第 6.5 节）。解码器的实现在 platform 里。

use crate::capture::Frame;

/// H.264 解码器。每次送进一帧 Annex B 格式的数据，返回解码出的最新一帧灰度画面；
/// 解码器还在攒数据时返回 None。返回的错误是给人看的原因。
pub trait H264Decoder {
    fn decode(&mut self, annexb: &[u8], timestamp_ms: u32) -> Result<Option<Frame>, String>;
}

/// 画面比最好的时候多落后这么多，就开始追帧。
pub const MAX_LAG_MS: i64 = 2_000;

/// 追帧（设计文档第 6.5 节）。
///
/// 用“收到的时间 - FLV 时间戳”衡量落后多少：这个差值越大，画面越旧。记下见过的最小差值
/// （离直播最近的时候），当前差值比它大出 [`MAX_LAG_MS`] 以上，说明网络卡过、积了一段旧画面，
/// 这时跳过非关键帧，等下一个关键帧再接着解。到了关键帧就以它为新的基准，
/// 免得网络一直慢时永远在跳帧。
#[derive(Debug, Default)]
pub struct CatchUp {
    best: Option<i64>,
    skipping: bool,
}

impl CatchUp {
    /// `received_ms` 是收到这一帧的时间（单调时钟，毫秒）。返回这一帧要不要解码。
    pub fn should_decode(&mut self, timestamp_ms: u32, key: bool, received_ms: u64) -> bool {
        let offset = received_ms as i64 - i64::from(timestamp_ms);
        let best = self.best.map_or(offset, |best| best.min(offset));
        self.best = Some(best);
        if self.skipping || offset - best > MAX_LAG_MS {
            if key {
                self.skipping = false;
                self.best = Some(offset);
                return true;
            }
            self.skipping = true;
            return false;
        }
        true
    }
}

    /// 创建解码器。电脑上没有 H.264 解码器（比如 Windows N 版没装媒体功能包）时返回原因。
    pub fn new() -> Result<Self, String> {

            format!(

        // SAFETY: 都是 COM 和 Media Foundation 的普通调用，参数都是本函数里创建的对象。

            CoInitializeEx(None, COINIT_MULTITHREADED).ok()?;

                CoCreateInstance(&CLSID_MSH264DecoderMFT, None, CLSCTX_INPROC_SERVER)?;
            // 低延迟：解出一帧就交出来，不为重排序攒帧。
            mft.GetAttributes()?.SetUINT32(&MF_LOW_LATENCY, 1)?;
            let input = MFCreateMediaType()?;
            input.SetGUID(&MF_MT_MAJOR_TYPE, &MFMediaType_Video)?;
            input.SetGUID(&MF_MT_SUBTYPE, &MFVideoFormat_H264)?;
            mft.SetInputType(0, &input, 0)?;
            let mut decoder = Self {
                mft: Some(mft),
                width: 0,
                height: 0,
                visible_width: 0,
                visible_height: 0,
                stride: 0,
            };
            decoder.choose_output()?;
            let mft = decoder.transform();
            mft.ProcessMessage(MFT_MESSAGE_NOTIFY_BEGIN_STREAMING, 0)?;
            mft.ProcessMessage(MFT_MESSAGE_NOTIFY_START_OF_STREAM, 0)?;
            Ok(decoder)
        }
    }

    fn transform(&self) -> &IMFTransform {
        self.mft.as_ref().expect("解码器只在丢弃时才取走")
    }

    /// 选 NV12 输出，记下尺寸。开始时和分辨率变化时调用。
    fn choose_output(&mut self) -> windows::core::Result<()> {
        // SAFETY: 同上。
        unsafe {
            let mut index = 0;
            loop {
                let candidate = self.transform().GetOutputAvailableType(0, index)?;
                if candidate.GetGUID(&MF_MT_SUBTYPE)? == MFVideoFormat_NV12 {
                    self.transform().SetOutputType(0, &candidate, 0)?;
                    let size = candidate.GetUINT64(&MF_MT_FRAME_SIZE)?;
                    self.width = (size >> 32) as u32;
                    self.height = size as u32;
                    self.stride = candidate
                        .GetUINT32(&MF_MT_DEFAULT_STRIDE)
                        .map_or(self.width, |stride| (stride as i32).unsigned_abs())
                        as usize;
                    (self.visible_width, self.visible_height) =
                        visible_size(&candidate, self.width, self.height);
                    return Ok(());
                }
                index += 1;
            }
        }
    }

    /// 取出解码器里所有解好的帧，只留最后一帧。
    fn drain(&mut self) -> windows::core::Result<Option<Frame>> {
        let mut latest = None;
        // SAFETY: 输出缓冲区由我们分配，锁住后只在长度范围内读。
        unsafe {
            loop {
                let info = self.transform().GetOutputStreamInfo(0)?;
                let buffer = MFCreateMemoryBuffer(info.cbSize)?;
                let sample = MFCreateSample()?;
                sample.AddBuffer(&buffer)?;
                let mut output = [MFT_OUTPUT_DATA_BUFFER {
                    dwStreamID: 0,
                    pSample: ManuallyDrop::new(Some(sample)),
                    dwStatus: 0,
                    pEvents: ManuallyDrop::new(None),
                }];
                let mut status = 0u32;
                let result = self.transform().ProcessOutput(0, &mut output, &mut status);
                ManuallyDrop::drop(&mut output[0].pSample);
                ManuallyDrop::drop(&mut output[0].pEvents);
                match result {
                    Ok(()) => {
                        let mut data = std::ptr::null_mut();
                        let mut len = 0u32;
                        buffer.Lock(&mut data, None, Some(&mut len))?;
                        let bytes = std::slice::from_raw_parts(data, len as usize);
                        latest = self.luma(bytes);
                        buffer.Unlock()?;
                    }
                    Err(error) if error.code() == MF_E_TRANSFORM_NEED_MORE_INPUT => {
                        return Ok(latest);
                    }
                    Err(error) if error.code() == MF_E_TRANSFORM_STREAM_CHANGE => {
                        self.choose_output()?;
                    }
                    Err(error) => return Err(error),
                }
            }
        }
    }

    /// 从 NV12 里取出显示区域的亮度平面。缓冲区比预期短时放弃这一帧。
    fn luma(&self, nv12: &[u8]) -> Option<Frame> {
        let (width, height) = (self.visible_width as usize, self.visible_height as usize);
        if width == 0 || height == 0 || nv12.len() < self.stride * (height - 1) + width {
            return None;
        }
        let mut luma = Vec::with_capacity(width * height);
        for row in 0..height {
            let start = row * self.stride;
            luma.extend_from_slice(&nv12[start..start + width]);
        }
        Some(Frame {
            width: self.visible_width,
            height: self.visible_height,
            luma,
        })
    }

    fn send(&mut self, annexb: &[u8], timestamp_ms: u32) -> windows::core::Result<Option<Frame>> {
        // SAFETY: 输入缓冲区由我们分配，复制的长度就是分配的长度。
        unsafe {
            let buffer = MFCreateMemoryBuffer(annexb.len() as u32)?;
            let mut data = std::ptr::null_mut();
            buffer.Lock(&mut data, None, None)?;
            std::ptr::copy_nonoverlapping(annexb.as_ptr(), data, annexb.len());
            buffer.Unlock()?;
            buffer.SetCurrentLength(annexb.len() as u32)?;
            let sample = MFCreateSample()?;
            sample.AddBuffer(&buffer)?;
            // Media Foundation 的时间单位是 100 纳秒。
            sample.SetSampleTime(i64::from(timestamp_ms) * 10_000)?;
            let mut latest = None;
            if let Err(error) = self.transform().ProcessInput(0, &sample, 0) {
                if error.code() != MF_E_NOTACCEPTING {
                    return Err(error);
                }
                latest = self.drain()?;
                self.transform().ProcessInput(0, &sample, 0)?;
            }
            Ok(self.drain()?.or(latest))
        }
    }
}

/// 显示区域：读 MF_MT_MINIMUM_DISPLAY_APERTURE，没有就用整个输出尺寸。
fn visible_size(media_type: &IMFMediaType, width: u32, height: u32) -> (u32, u32) {
    let mut area = MFVideoArea::default();
    let size = std::mem::size_of::<MFVideoArea>();
    // SAFETY: 缓冲区就是 area 本身，长度是它的大小。
    let read = unsafe {
        media_type.GetBlob(
            &MF_MT_MINIMUM_DISPLAY_APERTURE,
            std::slice::from_raw_parts_mut((&mut area as *mut MFVideoArea).cast::<u8>(), size),
            None,
        )
    };
    let (cx, cy) = (area.Area.cx, area.Area.cy);
    if read.is_ok() && cx > 0 && cy > 0 {
        ((cx as u32).min(width), (cy as u32).min(height))
    } else {
        (width, height)
    }
}

impl H264Decoder for MfH264Decoder {
    fn decode(&mut self, annexb: &[u8], timestamp_ms: u32) -> Result<Option<Frame>, String> {
        self.send(annexb, timestamp_ms)
            .map_err(|error| error.to_string())
    }
}

impl Drop for MfH264Decoder {
    fn drop(&mut self) {
        drop(self.mft.take());
        // SAFETY: 和 create 里的 MFStartup 配对。
        unsafe {
            let _ = MFShutdown();
        }
    }

//! 直播客户端（设计文档第 9 节）：不带任何凭证和 Cookie。
//! 调平台接口时只能访问该平台的接口域名，不跟随跳转；拉流时可以访问接口返回的任意 HTTPS 地址，
//! 允许跳转（CDN 会重定向）。

use std::time::Duration;

use reqwest::header::{HeaderValue, REFERER};
use url::Url;

/// 浏览器的 User-Agent。平台接口可能拒绝没有 User-Agent 的请求。
const USER_AGENT: &str = "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/130.0.0.0 Safari/537.36";
const API_TIMEOUT: Duration = Duration::from_secs(10);
const CONNECT_TIMEOUT: Duration = Duration::from_secs(10);

#[derive(Debug, thiserror::Error)]
pub enum LiveError {
    #[error("网络请求失败：{0}")]
    Network(reqwest::Error),
    #[error("直播平台返回 HTTP {0}")]
    Status(u16),
    #[error("直播平台返回的内容格式不对，接口可能已变更：{0}")]
    Format(String),
    #[error("请求被拦截：{0}")]
    Blocked(String),
    #[error("找不到这个直播间")]
    RoomNotFound,
    #[error("这个直播间没有 H.264 的 FLV 直播流")]
    NoStream,
    #[error("{0}")]
    Other(String),
}

impl LiveError {
    /// reqwest 的错误信息带完整网址，流地址后面有一长串签名参数，先去掉。
    pub(crate) fn network(error: reqwest::Error) -> Self {
        Self::Network(error.without_url())
    }
}

pub struct LiveClient {
    api: reqwest::Client,
    stream: reqwest::Client,
    /// 测试时允许访问本地假服务器（http://127.0.0.1）。
    allow_local: bool,
}

impl LiveClient {
    pub fn new() -> Result<Self, LiveError> {
        Self::build(false)
    }

    #[cfg(test)]
    pub(crate) fn for_tests() -> Self {
        Self::build(true).expect("构建测试客户端")
    }

    fn build(allow_local: bool) -> Result<Self, LiveError> {
        let api = reqwest::Client::builder()
            .user_agent(USER_AGENT)
            .redirect(reqwest::redirect::Policy::none())
            .timeout(API_TIMEOUT)
            .https_only(!allow_local)
            .build()
            .map_err(LiveError::network)?;
        let stream = reqwest::Client::builder()
            .user_agent(USER_AGENT)
            .redirect(reqwest::redirect::Policy::limited(5))
            .connect_timeout(CONNECT_TIMEOUT)
            .https_only(!allow_local)
            .build()
            .map_err(LiveError::network)?;
        Ok(Self {
            api,
            stream,
            allow_local,
        })
    }

    /// 调平台接口，返回 JSON。`hosts` 是这个平台允许访问的接口域名。
    pub(crate) async fn get_json(
        &self,
        url: Url,
        hosts: &[&str],
        referer: &'static str,
    ) -> Result<serde_json::Value, LiveError> {
        let host = url.host_str().unwrap_or_default();
        let local = self.allow_local && matches!(host, "127.0.0.1" | "localhost");
        if !hosts.contains(&host) && !local {
            return Err(LiveError::Blocked(format!("不允许访问 {host}")));
        }
        let response = self
            .api
            .get(url)
            .header(REFERER, HeaderValue::from_static(referer))
            .send()
            .await
            .map_err(LiveError::network)?;
        if !response.status().is_success() {
            return Err(LiveError::Status(response.status().as_u16()));
        }
        let bytes = response.bytes().await.map_err(LiveError::network)?;
        serde_json::from_slice(&bytes).map_err(|error| LiveError::Format(error.to_string()))
    }

    /// 打开一个直播流地址。只允许 HTTPS。
    pub(crate) async fn open_stream(
        &self,
        url: &str,
        referer: &'static str,
    ) -> Result<reqwest::Response, LiveError> {
        let response = self
            .stream
            .get(url)
            .header(REFERER, HeaderValue::from_static(referer))
            .send()
            .await
            .map_err(LiveError::network)?;
        if !response.status().is_success() {
            return Err(LiveError::Status(response.status().as_u16()));
        }
        Ok(response)
    }
}

    pub async fn resolve(&self, client: &LiveClient, room: u64) -> Result<StreamStatus, LiveError> {
        let room = room.to_string();
        let init = client
            .get_json(
                self.url("/room/v1/Room/room_init", &[("id", &room)]),
                &[API_HOST],
                REFERER,
            )
            .await?;
        if init["code"].as_i64() != Some(0) {
            return Err(LiveError::RoomNotFound);
        }
        let real_id = init["data"]["room_id"]
            .as_u64()
            .ok_or_else(|| LiveError::Format("room_init 的返回里没有 room_id".to_owned()))?
            .to_string();
        if init["data"]["live_status"].as_i64() != Some(1) {
            return Ok(StreamStatus::Offline);
        }
        let info = client
            .get_json(
                self.url(
                    "/xlive/web-room/v2/index/getRoomPlayInfo",
                    &[
                        ("room_id", &real_id),
                        ("protocol", "0,1"),
                        ("format", "0,1,2"),
                        ("codec", "0"),
                        ("qn", "10000"),
                        ("platform", "web"),
                    ],
                ),
                &[API_HOST],
                REFERER,
            )
            .await?;
        if info["code"].as_i64() != Some(0) {
            return Err(LiveError::Format(format!(
                "getRoomPlayInfo 返回 code={}",
                info["code"]
            )));
        }
        // 两次请求之间主播可能刚好下播，这时没有 playurl_info。
        if info["data"]["playurl_info"].is_null() {
            return Ok(StreamStatus::Offline);
        }
        let urls = flv_urls(&info["data"]["playurl_info"]["playurl"]["stream"]);
        if urls.is_empty() {
            return Err(LiveError::NoStream);
        }
        Ok(StreamStatus::Live {
            urls,
            referer: REFERER,
        })
    }
}

/// 挑出 HTTP-FLV、H.264 的地址：`host + base_url + extra`，每个 CDN 一个。
fn flv_urls(streams: &Value) -> Vec<String> {
    let mut urls = Vec::new();
    for stream in streams.as_array().into_iter().flatten() {
        if stream["protocol_name"] != "http_stream" {
            continue;
        }
        for format in stream["format"].as_array().into_iter().flatten() {
            if format["format_name"] != "flv" {
                continue;
            }
            for codec in format["codec"].as_array().into_iter().flatten() {
                if codec["codec_name"] != "avc" {
                    continue;
                }
                let base = codec["base_url"].as_str().unwrap_or_default();
                for info in codec["url_info"].as_array().into_iter().flatten() {
                    if let (Some(host), Some(extra)) = (info["host"].as_str(), info["extra"].as_str()) {
                        urls.push(format!("{host}{base}{extra}"));
                    }
                }
            }
        }
    }
    urls
}

//! 直播画面来源（设计文档第 6.5 节）：在自己的线程里取流、拉流、拆 FLV、解码，只留最新的一帧。
//! 扫描循环每次 `next_frame` 拿到的都是最新画面；识别比解码慢时，中间的帧直接丢掉。

use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::{Arc, Condvar, Mutex, MutexGuard};
use std::time::{Duration, Instant};

use mhy_carry_core::capture::{CaptureError, Frame, FrameSource, SourceInfo, SourceKind};
use mhy_carry_core::flv::{FlvError, FlvParser};
use mhy_carry_core::room::LiveRoom;
use mhy_carry_core::video::{CatchUp, H264Decoder};

use crate::client::{LiveClient, LiveError};
use crate::platforms::{Platforms, StreamStatus};

/// 怎么创建解码器。系统解码器（COM）只能在创建它的线程里用，所以交给拉流线程去创建。
pub type DecoderFactory = Box<dyn Fn() -> Result<Box<dyn H264Decoder>, String> + Send>;

/// 等新画面最多等这么久；等不到就报告当前状态，扫描会话据此显示“正在连接”“等待开播”。
const WAIT_FOR_FRAME: Duration = Duration::from_secs(1);

/// 拉流线程的节奏。测试里会调短。
#[derive(Debug, Clone)]
pub(crate) struct Timing {
    /// 没开播时隔多久再查一次。
    pub offline_poll: Duration,
    /// 这么久没收到数据就当断线。
    pub stall: Duration,
    /// 连续这么多次连不上就停止。
    pub max_failures: u32,
}

impl Default for Timing {
    fn default() -> Self {
        Self {
            offline_poll: Duration::from_secs(10),
            stall: Duration::from_secs(10),
            max_failures: 5,
        }
    }
}

#[derive(Debug, Clone, PartialEq, Eq)]
enum State {
    Connecting,
    Offline,
    Live,
    Failed(String),
}

struct Slot {
    state: State,
    frame: Option<Frame>,
}

struct Shared {
    slot: Mutex<Slot>,
    changed: Condvar,
    /// 扫描结束，拉流线程该退出了。
    closed: AtomicBool,
}

impl Shared {
    fn lock(&self) -> MutexGuard<'_, Slot> {
        self.slot
            .lock()
            .unwrap_or_else(|poisoned| poisoned.into_inner())
    }

    fn set_state(&self, state: State) {
        self.lock().state = state;
        self.changed.notify_all();
    }

    /// 放进最新的一帧，旧的没被取走就直接覆盖。
    fn publish(&self, frame: Frame) {
        let mut slot = self.lock();
        slot.frame = Some(frame);
        slot.state = State::Live;
        drop(slot);
        self.changed.notify_all();
    }

    fn closed(&self) -> bool {
        self.closed.load(Ordering::Relaxed)
    }
}

/// 直播画面来源。丢弃时通知拉流线程退出。
pub struct LiveSource {
    shared: Arc<Shared>,
    info: SourceInfo,
}

impl LiveSource {
    /// 开始拉这个直播间的流。马上返回；取流、连接都在后台线程里做。
    pub fn start(room: LiveRoom, decoder: DecoderFactory) -> Result<Self, LiveError> {
        Self::start_with(
            room,
            decoder,
            LiveClient::new()?,
            Platforms::official(),
            Timing::default(),
        )
    }

    pub(crate) fn start_with(
        room: LiveRoom,
        decoder: DecoderFactory,
        client: LiveClient,
        platforms: Platforms,
        timing: Timing,
    ) -> Result<Self, LiveError> {
        let info = SourceInfo::new(SourceKind::LiveStream, &room.to_string());
        let shared = Arc::new(Shared {
            slot: Mutex::new(Slot {
                state: State::Connecting,
                frame: None,
            }),
            changed: Condvar::new(),
            closed: AtomicBool::new(false),
        });
        let worker = Arc::clone(&shared);
        std::thread::Builder::new()
            .name("live-stream".to_owned())
            .spawn(move || run(&room, &decoder, &client, &platforms, &timing, &worker))
            .map_err(|error| LiveError::Other(format!("启动拉流线程失败：{error}")))?;
        Ok(Self { shared, info })
    }
}

impl FrameSource for LiveSource {
    fn next_frame(&mut self) -> Result<Frame, CaptureError> {
        let slot = self.shared.lock();
        let (mut slot, _) = self
            .shared
            .changed
            .wait_timeout_while(slot, WAIT_FOR_FRAME, |slot| {
                slot.frame.is_none() && !matches!(slot.state, State::Failed(_))
            })
            .unwrap_or_else(|poisoned| poisoned.into_inner());
        if let Some(frame) = slot.frame.take() {
            return Ok(frame);
        }
        Err(match &slot.state {
            State::Offline => CaptureError::Offline,
            State::Failed(message) => CaptureError::LiveFailed(message.clone()),
            // 在播却一秒没有新画面，多半是卡住了，也算正在连接。
            State::Connecting | State::Live => CaptureError::Connecting,
        })
    }

    fn describe(&self) -> SourceInfo {
        self.info.clone()
    }
}

impl Drop for LiveSource {
    fn drop(&mut self) {
        self.shared.closed.store(true, Ordering::Relaxed);
        self.shared.changed.notify_all();
    }
}

/// 拉流线程：取流 → 拉流 → 断了就重连，直到扫描结束或者彻底失败。
fn run(
    room: &LiveRoom,
    decoder: &DecoderFactory,
    client: &LiveClient,
    platforms: &Platforms,
    timing: &Timing,
    shared: &Shared,
) {
    let runtime = match tokio::runtime::Builder::new_current_thread()
        .enable_all()
        .build()
    {
        Ok(runtime) => runtime,
        Err(error) => {
            return shared.set_state(State::Failed(format!("启动拉流线程失败：{error}")));
        }
    };
    runtime.block_on(async {
        let mut failures = 0;
        let mut next_url = 0;
        while !shared.closed() {
            let reason = match platforms.resolve(client, room).await {
                Ok(StreamStatus::Offline) => {
                    shared.set_state(State::Offline);
                    failures = 0;
                    sleep_unless_closed(timing.offline_poll, shared).await;
                    continue;
                }
                Ok(StreamStatus::Live { urls, referer }) => {
                    // 取流结果里至少有一个地址。每次重连换下一个 CDN。
                    let url = &urls[next_url % urls.len()];
                    next_url += 1;
                    let pulled = pull(url, referer, decoder, client, timing, shared).await;
                    if pulled.fatal {
                        return shared.set_state(State::Failed(pulled.reason));
                    }
                    if pulled.got_frame {
                        failures = 0;
                    }
                    pulled.reason
                }
                // 房间不存在、没有能用的流，重试也没用。
                Err(error @ (LiveError::RoomNotFound | LiveError::NoStream)) => {
                    return shared.set_state(State::Failed(error.to_string()));
                }
                Err(error) => error.to_string(),
            };
            if shared.closed() {
                return;
            }
            failures += 1;
            if failures >= timing.max_failures {
                return shared.set_state(State::Failed(reason));
            }
            shared.set_state(State::Connecting);
        }
    });
}

/// 一次拉流的结果。
struct Pulled {
    /// 中间解出过画面。连续失败的次数据此清零。
    got_frame: bool,
    reason: String,
    /// 重连也没用的错误：不是 H.264、电脑没有解码器。
    fatal: bool,
}

/// 拉一个流地址，直到断线、出错或者扫描结束。
async fn pull(
    url: &str,
    referer: &'static str,
    decoder: &DecoderFactory,
    client: &LiveClient,
    timing: &Timing,
    shared: &Shared,
) -> Pulled {
    let ended = |reason: String, got_frame| Pulled {
        got_frame,
        reason,
        fatal: false,
    };
    // 每次连接都用新的解码器：断线后旧解码器里的状态没用了，分辨率也可能变了。
    let mut decoder = match decoder() {
        Ok(decoder) => decoder,
        Err(reason) => {
            return Pulled {
                got_frame: false,
                reason,
                fatal: true,
            };
        }
    };
    let mut response = match client.open_stream(url, referer).await {
        Ok(response) => response,
        Err(error) => return ended(error.to_string(), false),
    };
    let mut parser = FlvParser::new();
    let mut catch_up = CatchUp::default();
    let started = Instant::now();
    let mut got_frame = false;
    while !shared.closed() {
        let chunk = match tokio::time::timeout(timing.stall, response.chunk()).await {
            Err(_) => {
                return ended(
                    format!("{} 秒没收到直播数据", timing.stall.as_secs()),
                    got_frame,
                );
            }
            Ok(Err(error)) => return ended(LiveError::network(error).to_string(), got_frame),
            Ok(Ok(None)) => return ended("直播流断开了".to_owned(), got_frame),
            Ok(Ok(Some(chunk))) => chunk,
        };
        let frames = match parser.push(&chunk) {
            Ok(frames) => frames,
            Err(error @ FlvError::NotH264) => {
                return Pulled {
                    got_frame,
                    reason: error.to_string(),
                    fatal: true,
                };
            }
            Err(error) => return ended(error.to_string(), got_frame),
        };
        for video in frames {
            let received_ms = started.elapsed().as_millis() as u64;
            if !catch_up.should_decode(video.timestamp_ms, video.key, received_ms) {
                continue;
            }
            match decoder.decode(&video.annexb, video.timestamp_ms) {
                Ok(Some(frame)) => {
                    got_frame = true;
                    shared.publish(frame);
                }
                Ok(None) => {}
                Err(message) => return ended(format!("解码失败：{message}"), got_frame),
            }
        }
    }
    ended(String::new(), got_frame)
}

/// 分小段睡，扫描结束时能尽快退出线程。
async fn sleep_unless_closed(duration: Duration, shared: &Shared) {
    let deadline = Instant::now() + duration;
    while !shared.closed() {
        let left = deadline.saturating_duration_since(Instant::now());
        if left.is_zero() {
            return;
        }
        tokio::time::sleep(left.min(Duration::from_millis(200))).await;
    }
}

/// 会记进设置，下次自动填上。
#[tauri::command(rename_all = "snake_case")]
pub async fn scan_start(
    app: AppHandle,
    target: TargetKind,
    id: Option<u32>,
    room: Option<String>,
) -> CommandResult {
    let (stop, stop_signal) = mpsc::channel(1);
    let (idle_timeout, active, auto_confirm) = {
        let shared = app.state::<Shared>();
        let mut model = shared.lock();
        if model.scanning() {
            return Ok(());
        }
        if model.bind.in_progress() {
            return Err("绑定中不能开始扫描。".to_owned());
        }
        if target == TargetKind::Live {
            let room = room.clone().unwrap_or_default();
            parse_room(&room).map_err(|error| error.to_string())?;
            // 记住这次的直播间。写不进去也不影响这次扫描。
            model.settings.scan.live_room = room.trim().to_owned();
            let _ = model.settings.save(&shared.settings_path);
        }
        model.scan_stop = Some(stop);
        model.last_notice = None;
        model.notice_at = None;
        (
            model.settings.scan.idle_timeout(),
            model.settings.active_account.clone(),
            model.settings.scan.auto_confirm,
        )
    };
    let job = prepare_job(&app, target, id, room.as_deref(), idle_timeout, active.as_deref());
    match job {
        Ok((mut job, account_id)) => {
            job.auto_confirm = auto_confirm;
            app.state::<Shared>().lock().scan_account = Some(account_id);
            scan::spawn(app, job, stop_signal);
            Ok(())
        }
        Err(message) => {
            update(&app, |model| model.scan_stop = None);
            Err(message)
        }
    }
}

**任务 14 的独立审查**（2026-10-15）：没有安全问题；有 2 个中等问题、8 个低优先级问题。改动如下：

- **中等 1（已修）：** 打开流地址没有超时，服务器接受连接却不回应时，拉流线程会一直卡住，扫描停止后也不退出。

- **中等 2（已修，改了设计第 6.5 节）：** 原来重连之间没有间隔，网络闪断几秒，5 次失败就会瞬间用完；而一连上就断的流又会无限重连。现在的规则：
  - 解出画面后又拉了 30 秒以上才断，立刻重连；
  - 连不上就按 1、2、4…30 秒退避；
  - 至少 5 次、并且持续 1 分钟以上才停止。
- **低 3（已修）：** 从“没开播”到开播，连上之前状态一直是“等待开播”。现在开始拉流前先设成“正在连接”。
- **低 4（已修）：** 跳转时 reqwest 会把上一跳带签名的地址当作 Referer 发出去。流客户端加了 `.referer(false)`。

- **低 6（已修）：** `room_init` 返回任何非 0 的 code 都当房间不存在、永久停止。现在只有实测的 60004 算房间不存在，其他错误码按连不上处理。
