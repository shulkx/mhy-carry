# MhyCarry M2 实现计划：自动扫描

> **For agentic workers:** REQUIRED SUB-SKILL: Use executing-plans to implement this plan task-by-task（按 CLAUDE.md，在当前会话里按顺序执行，不要每个任务开一个子代理）. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 做出 `mhy-carry-cli watch [--target auto|window|monitor]`：自动截图、识别登录二维码，发现后在终端里问你，确认后登录。三种截图目标各用真实账号成功登录一次（设计文档第 13 节的 M2 验收标准）。

**架构：** 新的纯逻辑都放在 `core`：外部文本清理、画面来源类型、二维码识别（rxing 从 `cli` 挪过来）、确认策略、扫码会话状态机 `ScanSession`。`ScanSession` 不开线程、不做 I/O，吃事件、吐动作和状态快照（设计文档第 6.3 节）。`api` 把扫码登录三步合成一个方法，并把接口错误分好类交给会话。`platform` 用 xcap 的 GDI 后端截窗口所在的屏幕区域（M1 实测选定），只在 Windows 上编译。`cli watch` 是很薄的运行循环：一个截图线程，加上 tokio 主循环负责问你和联网。

**技术栈：** 在 M1 基础上新增：xcap 0.9（GDI 后端）、windows 0.62（查进程的 exe 路径）。tokio 加 `sync` 功能。rxing 改由 `core` 依赖。

**设计文档：** [docs/design/2026-10-11-mhy-carry-design.md](../design/2026-10-11-mhy-carry-design.md)，重点是第 5、6.2、6.3、10、11、14 节。

**状态（2026-10-13）：** 任务 1–13 已完成，任务 14（真实账号实测）等用户操作。实际执行和计划的差异：推送后的独立审查发现了几处问题，已另外提交修复（不在下面的任务里）：硬性规则同时看会话目标；登录中途停止时等登录结果；只有新出现的登录码才让超时重新计时；超时最短 30 秒；外部文本清理补全零宽和格式字符；提问前清空终端里预先敲好的输入；确认和登录期间截图暂停、丢掉过时画面；指定窗口被隐藏时按暂停处理；自动模式只在游戏在最前面时扫描（用户确认的方案，设计文档第 6.2、6.3 节已同步）。

//! 外部文本（窗口标题、服务器返回的应用名等）显示前的清理。

/// 把控制字符和双向文本控制符换成空格，再去掉首尾空白。
///
/// 窗口标题这类文本来自别的程序。里面的回车、ESC 这类字符打到终端上，可以改写
/// 已经显示的内容，比如伪造确认提示；双向文本控制符可以让文字倒着显示。
pub fn printable(text: &str) -> String {
    text.chars()
        .map(|c| {
            if c.is_control() || is_bidi_control(c) {
                ' '
            } else {
                c
            }
        })
        .collect::<String>()
        .trim()
        .to_owned()
}

fn is_bidi_control(c: char) -> bool {
    matches!(
        c,
        '\u{200E}' | '\u{200F}' | '\u{202A}'..='\u{202E}' | '\u{2066}'..='\u{2069}'
    )
}
```

use serde::Serialize;

use crate::text::printable;

/// 一帧灰度画面，每个像素一个字节，逐行排列。
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Frame {
    pub width: u32,
    pub height: u32,
    pub luma: Vec<u8>,
}

/// 截图目标的种类。
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize)]
#[serde(rename_all = "snake_case")]
pub enum SourceKind {
    /// 自动找到的游戏窗口。
    GameWindow,
    /// 你从列表里选的窗口，比如正在看直播的浏览器。
    PickedWindow,
    /// 整个显示器。
    Monitor,
}

/// 画面来自哪里，用来告诉你二维码是在哪发现的。
#[derive(Debug, Clone, PartialEq, Eq, Serialize)]
pub struct SourceInfo {
    pub kind: SourceKind,
    /// 给人看的描述，比如 `YuanShen.exe（原神）`。
    pub label: String,
}

impl SourceInfo {
    /// `label` 常带着窗口标题这类外部文本，先清理掉控制字符。
    pub fn new(kind: SourceKind, label: &str) -> Self {
        Self {
            kind,
            label: printable(label),
        }
    }
}

#[derive(Debug, Clone, PartialEq, Eq, thiserror::Error)]
pub enum CaptureError {
    /// 自动模式下还没找到游戏窗口。
    #[error("还没找到游戏窗口")]
    NotFound,
    #[error("窗口已最小化")]
    Minimized,
    /// 指定的窗口关了，或者指定的显示器断开了。
    #[error("截图目标已经不在了")]
    Gone,
    #[error("截图失败：{0}")]
    Failed(String),
}

/// 一帧帧地提供画面。
pub trait FrameSource {
    fn next_frame(&mut self) -> Result<Frame, CaptureError>;
    /// 最近一次截到的画面来自哪里。
    fn describe(&self) -> SourceInfo;
}
```

//! 二维码识别（设计文档第 5 节）。v1 用 rxing，只开了它的二维码功能（见根目录 Cargo.toml）。

use std::panic;

use crate::capture::Frame;

/// 从一帧里识别出所有二维码的文本。
pub trait QrDecoder {
    fn decode(&self, frame: Frame) -> Vec<String>;
}

#[derive(Debug, Default, Clone, Copy)]
pub struct RxingDecoder;

impl QrDecoder for RxingDecoder {
    fn decode(&self, frame: Frame) -> Vec<String> {
        let Frame {
            width,
            height,
            luma,
        } = frame;
        if width == 0 || height == 0 || luma.len() != width as usize * height as usize {
            return Vec::new();
        }
        // rxing 是从 Java 移植的，遇到奇怪的画面可能 panic。一帧识别失败不能让整个扫描停下。
        let result = panic::catch_unwind(move || {
            rxing::helpers::detect_multiple_in_luma(luma, width, height)
        });
        match result {
            Ok(Ok(found)) => found.iter().map(|r| r.getText().to_owned()).collect(),
            // 画面里没有二维码时 rxing 也返回错误，当作“没识别出来”。
            Ok(Err(_)) | Err(_) => Vec::new(),
        }
    }
}
```

//! 确认策略（设计文档第 5 节）：识别到合法的登录二维码后怎么做。

use crate::capture::{SourceInfo, SourceKind};
use crate::qr::LoginQr;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Decision {
    /// 问你。
    AskUser,
    /// 直接登录。
    AutoConfirm,
    /// 忽略这个二维码。
    Ignore,
}

pub trait ConfirmPolicy {
    fn decide(&mut self, source: &SourceInfo, qr: &LoginQr) -> Decision;
}

/// v1 唯一的策略：每次都问你。
#[derive(Debug, Default, Clone, Copy)]
pub struct AlwaysAsk;

impl ConfirmPolicy for AlwaysAsk {
    fn decide(&mut self, _source: &SourceInfo, _qr: &LoginQr) -> Decision {
        Decision::AskUser
    }
}

/// 硬性规则：画面来自指定窗口或显示器时，永远不自动确认。那里的画面可能是
/// 别人的直播，二维码可能是别人故意放的。任何策略的决定都要先过这一关。
pub fn enforce_hard_rules(decision: Decision, source: &SourceInfo) -> Decision {
    match (decision, source.kind) {
        (Decision::AutoConfirm, SourceKind::PickedWindow | SourceKind::Monitor) => {
            Decision::AskUser
        }
        (decision, _) => decision,
    }
}

//! 扫码会话状态机（设计文档第 5、6.2、6.3 节）。
//!
//! 纯逻辑：不开线程，不做 I/O。运行循环把发生的事（[`Event`]）喂进来，它返回下一步
//! 要做的事（[`Action`]），并更新给界面显示的状态快照（[`ScanStatus`]）。

use std::collections::HashSet;
use std::fmt;
use std::time::{Duration, Instant};

use serde::Serialize;

use crate::capture::{CaptureError, FrameSource, SourceInfo, SourceKind};
use crate::confirm::{ConfirmPolicy, Decision, enforce_hard_rules};
use crate::decode::QrDecoder;
use crate::qr::{LoginQr, parse_login_qr};
use crate::text::printable;

/// 连续截图失败这么多次就停止（设计文档第 10 节）。
pub const MAX_CAPTURE_FAILURES: u32 = 10;

/// 当前时间：`instant` 用来算超时，`unix`（Unix 秒）用来判断二维码有没有过期。
#[derive(Debug, Clone, Copy)]
pub struct Now {
    pub instant: Instant,
    pub unix: i64,
}

impl Now {
    pub fn current() -> Self {
        Self {
            instant: Instant::now(),
            unix: jiff::Timestamp::now().as_second(),
        }
    }
}

/// 截一帧（或者没截成）的结果。
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Observation {
    /// 截到一帧，`texts` 是里面识别出的所有二维码文本。
    Frame {
        source: SourceInfo,
        texts: Vec<String>,
    },
    /// 自动模式下还没找到游戏窗口，或者游戏窗口关了。
    TargetMissing,
    /// 窗口最小化了。
    TargetMinimized,
    /// 指定的窗口关了，或者指定的显示器断开了。
    TargetGone,
    /// 这一帧没截成。
    CaptureFailed(String),
}

/// 截一帧并识别。截图线程反复调用它，把结果交给会话。
pub fn observe(source: &mut dyn FrameSource, decoder: &dyn QrDecoder) -> Observation {
    match source.next_frame() {
        Ok(frame) => Observation::Frame {
            source: source.describe(),
            texts: decoder.decode(frame),
        },
        Err(CaptureError::NotFound) => Observation::TargetMissing,
        Err(CaptureError::Minimized) => Observation::TargetMinimized,
        Err(CaptureError::Gone) => Observation::TargetGone,
        Err(CaptureError::Failed(message)) => Observation::CaptureFailed(message),
    }
}

/// 接口调用失败的原因。运行循环把接口错误分好类再喂进来（设计文档第 10 节）。
#[derive(Debug, Clone, PartialEq, Eq, thiserror::Error)]
pub enum Failure {
    /// 凭证失效（retcode -100），扫描要停止。
    #[error("账号凭证已失效")]
    CredentialInvalid,
    /// 二维码过期或已被使用。
    #[error("二维码已过期")]
    QrExpired,
    /// 服务器认定的登录目标不是这个游戏。
    #[error("服务器说这是“{app_name}”的登录码")]
    AppMismatch { app_name: String },
    /// 其他错误，比如网络错误、未知错误码。内容是给人看的原因。
    #[error("{0}")]
    Other(String),
}

/// 喂给会话的事件。
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Event {
    /// 会话开始时检查凭证的结果。
    CredentialChecked(Result<(), Failure>),
    /// 截图线程报告的一帧。
    Observed(Observation),
    /// 你对确认提问的回答，`true` 表示登录。
    Answered(bool),
    /// 登录三步的结果。
    LoginFinished(Result<(), Failure>),
    /// 时间流逝。运行循环在一段时间没有新画面时喂一次，用来判断超时。
    Tick,
    /// 你要求停止。
    StopRequested,
}

/// 会话要运行循环做的事。
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Action {
    /// 检查凭证，结果用 [`Event::CredentialChecked`] 喂回来。
    CheckCredential,
    /// 问你要不要登录，回答用 [`Event::Answered`] 喂回来。
    Ask(Prompt),
    /// 执行登录三步，结果用 [`Event::LoginFinished`] 喂回来。
    Login(LoginQr),
    /// 会话结束，停止截图。结束原因在状态快照里。
    Finish,
}

/// 确认提问的内容（设计文档第 6.2 节第 5 步）。
#[derive(Debug, Clone, PartialEq, Eq, Serialize)]
pub struct Prompt {
    /// 游戏名，取自程序自己的游戏配置，不用二维码里的文字。
    pub game: &'static str,
    /// 画面来源，比如 `YuanShen.exe（原神）`。
    pub source: String,
    /// 打码后的 uid。
    pub masked_uid: String,
}

impl Prompt {
    /// 确认框里的问题。
    pub fn question(&self) -> String {
        format!(
            "在 {}中发现{}登录二维码。用账号 {} 登录？确认后，显示这个二维码的设备将登录你的账号。",
            self.source, self.game, self.masked_uid
        )
    }
}

/// 扫描会话的状态快照（设计文档第 6.3 节）。界面只按它显示。
#[derive(Debug, Clone, PartialEq, Eq, Serialize)]
#[serde(tag = "kind", rename_all = "snake_case")]
pub enum ScanStatus {
    /// 没在扫描，`last` 是上次结束的原因。
    Idle { last: Option<StopReason> },
    /// 检查账号凭证。
    CheckingCredential,
    /// 自动模式下等游戏窗口出现，`game` 是游戏名。
    WaitingForWindow { game: String },
    /// 窗口最小化了，恢复后继续。
    Paused,
    /// 正在扫描，`notice` 是最近一条提示。
    Scanning {
        source: String,
        notice: Option<Notice>,
    },
    /// 等你确认。这期间不处理新的画面。
    AwaitingConfirm { prompt: Prompt },
    /// 正在登录。这期间不处理新的画面。
    LoggingIn,
}

impl ScanStatus {
    /// 扫描中附带的最近一条提示。
    pub fn notice(&self) -> Option<&Notice> {
        match self {
            ScanStatus::Scanning { notice, .. } => notice.as_ref(),
            _ => None,
        }
    }
}

impl fmt::Display for ScanStatus {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        match self {
            ScanStatus::Idle { last: None } => write!(f, "未在扫描"),
            ScanStatus::Idle { last: Some(reason) } => write!(f, "已停止：{reason}"),
            ScanStatus::CheckingCredential => write!(f, "检查账号凭证…"),
            ScanStatus::WaitingForWindow { game } => write!(f, "等待{game}窗口…"),
            ScanStatus::Paused => write!(f, "窗口已最小化，恢复后继续"),
            ScanStatus::Scanning { source, .. } => write!(f, "正在扫描 {source}"),
            ScanStatus::AwaitingConfirm { .. } => write!(f, "等你确认是否登录"),
            ScanStatus::LoggingIn => write!(f, "正在登录…"),
        }
    }
}

/// 扫描结束的原因。
#[derive(Debug, Clone, PartialEq, Eq, Serialize)]
#[serde(tag = "kind", rename_all = "snake_case")]
pub enum StopReason {
    LoggedIn { game: String },
    UserStopped,
    IdleTimeout { secs: u64 },
    CredentialInvalid,
    TargetGone,
    CaptureFailing { message: String },
    CredentialCheckFailed { message: String },
}

impl fmt::Display for StopReason {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        match self {
            StopReason::LoggedIn { game } => {
                write!(f, "登录成功，显示二维码的{game}已登录你的账号")
            }
            StopReason::UserStopped => write!(f, "你手动停止了扫描"),
            StopReason::IdleTimeout { secs } => write!(f, "连续 {secs} 秒没发现登录二维码"),
            StopReason::CredentialInvalid => write!(f, "账号凭证已失效，请重新绑定"),
            StopReason::TargetGone => write!(f, "指定的窗口已关闭，或指定的显示器已断开"),
            StopReason::CaptureFailing { message } => {
                write!(f, "截图连续失败 {MAX_CAPTURE_FAILURES} 次：{message}")
            }
            StopReason::CredentialCheckFailed { message } => {
                write!(f, "检查账号凭证时出错：{message}")
            }
        }
    }
}

/// 扫描中的提示，不会让扫描停下。
#[derive(Debug, Clone, PartialEq, Eq, Serialize)]
#[serde(tag = "kind", rename_all = "snake_case")]
pub enum Notice {
    MultipleQrs,
    QrExpired,
    AppMismatch { app_name: String, game: String },
    Declined,
    LoginFailed { message: String },
}

impl fmt::Display for Notice {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        match self {
            Notice::MultipleQrs => write!(f, "画面里有多个登录二维码，无法确定要登录哪一个"),
            Notice::QrExpired => write!(f, "二维码已过期或已被使用，等游戏刷新"),
            Notice::AppMismatch { app_name, game } => {
                write!(f, "服务器说这是“{app_name}”的登录码，不是{game}，已取消")
            }
            Notice::Declined => write!(f, "你取消了这次登录，同一个码不会再问"),
            Notice::LoginFailed { message } => write!(f, "登录失败：{message}"),
        }
    }
}

/// 一次扫码会话。
pub struct ScanSession {
    /// 开始时选的截图目标。自动模式下 `label` 是游戏名。
    target: SourceInfo,
    masked_uid: String,
    idle_timeout: Duration,
    policy: Box<dyn ConfirmPolicy + Send>,
    status: ScanStatus,
    /// 超时从这个时间点算起：会话开始、上一次发现合法登录码、你回答、登录结束。
    idle_since: Instant,
    capture_failures: u32,
    /// 本次会话处理过的 ticket，同一个只处理一次（设计文档第 6.2 节第 4 步）。
    seen: HashSet<String>,
    /// 正在确认或登录的二维码。
    pending: Option<LoginQr>,
    /// 最近一帧画面的来源，回到扫描状态时显示。
    source_label: String,
    notice: Option<Notice>,
}

impl ScanSession {
    /// 开始一个会话。第一个动作总是检查凭证（设计文档第 6.2 节）。
    pub fn start(
        target: SourceInfo,
        masked_uid: String,
        idle_timeout: Duration,
        policy: Box<dyn ConfirmPolicy + Send>,
        now: Now,
    ) -> (Self, Action) {
        let session = Self {
            source_label: target.label.clone(),
            target,
            masked_uid,
            idle_timeout,
            policy,
            status: ScanStatus::CheckingCredential,
            idle_since: now.instant,
            capture_failures: 0,
            seen: HashSet::new(),
            pending: None,
            notice: None,
        };
        (session, Action::CheckCredential)
    }

    pub fn status(&self) -> &ScanStatus {
        &self.status
    }

    pub fn is_finished(&self) -> bool {
        matches!(self.status, ScanStatus::Idle { .. })
    }

    /// 处理一个事件，返回下一步要做的事。会话结束后不再处理任何事件。
    pub fn handle(&mut self, event: Event, now: Now) -> Option<Action> {
        if self.is_finished() {
            return None;
        }
        if matches!(event, Event::Tick | Event::Observed(_)) && self.idle_expired(now) {
            let secs = self.idle_timeout.as_secs();
            return Some(self.finish(StopReason::IdleTimeout { secs }));
        }
        match event {
            Event::CredentialChecked(result) => self.on_credential_checked(result, now),
            Event::Observed(observation) => self.on_observed(observation, now),
            Event::Answered(yes) => self.on_answered(yes, now),
            Event::LoginFinished(result) => self.on_login_finished(result, now),
            Event::Tick => None,
            Event::StopRequested => Some(self.finish(StopReason::UserStopped)),
        }
    }

    /// 是否在看画面：等窗口、暂停、扫描。只有这时才处理画面，也只有这时才计算超时。
    fn watching(&self) -> bool {
        matches!(
            self.status,
            ScanStatus::WaitingForWindow { .. } | ScanStatus::Paused | ScanStatus::Scanning { .. }
        )
    }

    fn idle_expired(&self, now: Now) -> bool {
        self.watching() && now.instant.duration_since(self.idle_since) >= self.idle_timeout
    }

    fn finish(&mut self, reason: StopReason) -> Action {
        self.status = ScanStatus::Idle { last: Some(reason) };
        self.pending = None;
        Action::Finish
    }

    fn show_scanning(&mut self) {
        self.status = ScanStatus::Scanning {
            source: self.source_label.clone(),
            notice: self.notice.clone(),
        };
    }

    fn show_waiting(&mut self) {
        self.status = ScanStatus::WaitingForWindow {
            game: self.target.label.clone(),
        };
    }

    fn on_credential_checked(&mut self, result: Result<(), Failure>, now: Now) -> Option<Action> {
        if self.status != ScanStatus::CheckingCredential {
            return None;
        }
        match result {
            Ok(()) => {
                self.idle_since = now.instant;
                if self.target.kind == SourceKind::GameWindow {
                    self.show_waiting();
                } else {
                    self.show_scanning();
                }
                None
            }
            Err(Failure::CredentialInvalid) => Some(self.finish(StopReason::CredentialInvalid)),
            Err(other) => Some(self.finish(StopReason::CredentialCheckFailed {
                message: printable(&other.to_string()),
            })),
        }
    }

    fn on_observed(&mut self, observation: Observation, now: Now) -> Option<Action> {
        // 检查凭证、等你确认、登录期间不处理画面（设计文档第 6.2 节第 2 步）。
        if !self.watching() {
            return None;
        }
        match observation {
            Observation::TargetMissing => {
                self.show_waiting();
                None
            }
            Observation::TargetMinimized => {
                self.status = ScanStatus::Paused;
                None
            }
            // 自动模式下游戏窗口关了，游戏可能会重开，回去等着；指定的目标没了就停止。
            Observation::TargetGone if self.target.kind == SourceKind::GameWindow => {
                self.show_waiting();
                None
            }
            Observation::TargetGone => Some(self.finish(StopReason::TargetGone)),
            Observation::CaptureFailed(message) => {
                self.capture_failures += 1;
                if self.capture_failures >= MAX_CAPTURE_FAILURES {
                    Some(self.finish(StopReason::CaptureFailing {
                        message: printable(&message),
                    }))
                } else {
                    None
                }
            }
            Observation::Frame { source, texts } => {
                self.capture_failures = 0;
                self.on_frame(source, &texts, now)
            }
        }
    }

    fn on_frame(&mut self, source: SourceInfo, texts: &[String], now: Now) -> Option<Action> {
        self.source_label = source.label.clone();
        // 同一个码在一帧里可能被识别出两次，按 ticket 去重。
        let mut codes: Vec<LoginQr> = Vec::new();
        for text in texts {
            if let Ok(qr) = parse_login_qr(text, now.unix)
                && !codes.iter().any(|code| code.ticket == qr.ticket)
            {
                codes.push(qr);
            }
        }
        if codes.is_empty() {
            self.show_scanning();
            return None;
        }
        // 发现了合法的登录码，超时重新计时。
        self.idle_since = now.instant;
        if codes.len() > 1 {
            // 不弹窗：确认框里的文字分辨不出是哪一个（设计文档第 6.2 节第 2 步）。
            self.notice = Some(Notice::MultipleQrs);
            self.show_scanning();
            return None;
        }
        let qr = codes.remove(0);
        if !self.seen.insert(qr.ticket.clone()) {
            self.show_scanning();
            return None;
        }
        match enforce_hard_rules(self.policy.decide(&source, &qr), &source) {
            Decision::Ignore => {
                self.show_scanning();
                None
            }
            Decision::AskUser => {
                let prompt = Prompt {
                    game: qr.game.display_name,
                    source: source.label,
                    masked_uid: self.masked_uid.clone(),
                };
                self.status = ScanStatus::AwaitingConfirm {
                    prompt: prompt.clone(),
                };
                self.pending = Some(qr);
                Some(Action::Ask(prompt))
            }
            Decision::AutoConfirm => {
                self.status = ScanStatus::LoggingIn;
                self.pending = Some(qr.clone());
                Some(Action::Login(qr))
            }
        }
    }

    fn on_answered(&mut self, yes: bool, now: Now) -> Option<Action> {
        if !matches!(self.status, ScanStatus::AwaitingConfirm { .. }) {
            return None;
        }
        self.idle_since = now.instant;
        match (yes, self.pending.clone()) {
            (true, Some(qr)) => {
                self.status = ScanStatus::LoggingIn;
                Some(Action::Login(qr))
            }
            _ => {
                self.pending = None;
                self.notice = Some(Notice::Declined);
                self.show_scanning();
                None
            }
        }
    }

    fn on_login_finished(&mut self, result: Result<(), Failure>, now: Now) -> Option<Action> {
        if self.status != ScanStatus::LoggingIn {
            return None;
        }
        let game = self.pending.take().map_or("", |qr| qr.game.display_name);
        self.idle_since = now.instant;
        // 只有凭证失效才停止；其他失败只影响这一个二维码（设计文档第 6.2 节第 7 步）。
        let notice = match result {
            Ok(()) => {
                return Some(self.finish(StopReason::LoggedIn {
                    game: game.to_owned(),
                }));
            }
            Err(Failure::CredentialInvalid) => {
                return Some(self.finish(StopReason::CredentialInvalid));
            }
            Err(Failure::QrExpired) => Notice::QrExpired,
            Err(Failure::AppMismatch { app_name }) => Notice::AppMismatch {
                app_name: printable(&app_name),
                game: game.to_owned(),
            },
            Err(Failure::Other(message)) => Notice::LoginFailed {
                message: printable(&message),
            },
        };
        self.notice = Some(notice);
        self.show_scanning();
        None
    }
}

//! 截图目标的纯计算部分：进程名匹配、窗口落在显示器上的哪一块。不调用系统 API。

/// 屏幕上的一个矩形，单位是物理像素。
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Rect {
    pub x: i32,
    pub y: i32,
    pub width: u32,
    pub height: u32,
}

/// 窗口落在显示器上的那一块，坐标相对于显示器左上角。窗口完全不在这个显示器上时返回 None。
pub fn visible_region(window: Rect, monitor: Rect) -> Option<Rect> {
    let (wx, wy) = (i64::from(window.x), i64::from(window.y));
    let (mx, my) = (i64::from(monitor.x), i64::from(monitor.y));
    let left = wx.max(mx);
    let top = wy.max(my);
    let right = (wx + i64::from(window.width)).min(mx + i64::from(monitor.width));
    let bottom = (wy + i64::from(window.height)).min(my + i64::from(monitor.height));
    if right <= left || bottom <= top {
        return None;
    }
    Some(Rect {
        x: (left - mx) as i32,
        y: (top - my) as i32,
        width: (right - left) as u32,
        height: (bottom - top) as u32,
    })
}

/// 路径里的文件名，比如 `E:\games\YuanShen.exe` → `YuanShen.exe`。
pub fn exe_name(path: &str) -> &str {
    path.rsplit(['\\', '/']).next().unwrap_or(path)
}

/// 进程的 exe 文件名是否在列表里。Windows 的文件名不区分大小写。
pub fn is_listed_exe(exe: &str, names: &[&str]) -> bool {
    names.iter().any(|name| name.eq_ignore_ascii_case(exe))
}
```

//! Windows 上的截图（设计文档第 6.2、14 节）：xcap 的 GDI 后端，截窗口所在的那块屏幕区域。
//!
//! 截图目标只记窗口句柄或显示器编号，每一帧都重新找一次：窗口关了、最小化了、
//! 显示器断开了，都能马上发现。

use mhy_carry_core::capture::{CaptureError, Frame, FrameSource, SourceInfo, SourceKind};
use mhy_carry_core::games::GameProfile;
use mhy_carry_core::text::printable;
use windows::Win32::Foundation::CloseHandle;
use windows::Win32::System::Threading::{
    OpenProcess, PROCESS_NAME_WIN32, PROCESS_QUERY_LIMITED_INFORMATION,
    QueryFullProcessImageNameW,
};
use windows::core::PWSTR;
use xcap::image::{DynamicImage, RgbaImage};
use xcap::{Monitor, Window, XCapError};

/// 进程 exe 的完整路径。
///
/// 不用 xcap 的 `app_name()`：它优先返回 exe 版本信息里的描述，不一定是文件名。
/// 用 `PROCESS_QUERY_LIMITED_INFORMATION` 打开进程，以普通权限运行也能查到以管理员权限运行的游戏。
pub fn process_path(pid: u32) -> Option<String> {
    // SAFETY: 只把栈上缓冲区的指针和长度交给系统调用，句柄用完就关。
    unsafe {
        let handle = OpenProcess(PROCESS_QUERY_LIMITED_INFORMATION, false, pid).ok()?;
        let mut buffer = [0u16; 1024];
        let mut len = buffer.len() as u32;
        let result = QueryFullProcessImageNameW(
            handle,
            PROCESS_NAME_WIN32,
            PWSTR(buffer.as_mut_ptr()),
            &mut len,
        );
        let _ = CloseHandle(handle);
        result.ok()?;
        Some(String::from_utf16_lossy(&buffer[..len as usize]))
    }
}

/// 列出有标题的可见窗口，给你选“指定窗口”。最小化的窗口也在里面。
pub fn list_windows() -> Result<Vec<WindowTarget>, CaptureError> {
    let mut targets = Vec::new();
    for window in Window::all().map_err(failed)? {
        let title = window.title().unwrap_or_default();
        if title.trim().is_empty() {
            continue;
        }
        let Ok(id) = window.id() else {
            continue;
        };
        let exe = window
            .pid()
            .ok()
            .and_then(process_path)
            .map(|path| exe_name(&path).to_owned())
            .unwrap_or_default();
        targets.push(WindowTarget {
            id,
            label: printable(&format!("{title}（{exe}）")),
        });
    }
    Ok(targets)
}

/// 自动模式：按游戏配置里的进程名找游戏窗口。
pub struct GameWindowSource {
    games: &'static [GameProfile],
    /// 找到的游戏窗口：窗口句柄和来源描述。
    found: Option<(u32, SourceInfo)>,
}

impl GameWindowSource {
    pub fn new(games: &'static [GameProfile]) -> Self {
        Self { games, found: None }
    }

    fn search(&self) -> Result<Option<(Window, SourceInfo)>, CaptureError> {
        for window in Window::all().map_err(failed)? {
            let Ok(pid) = window.pid() else {
                continue;
            };
            let Some(path) = process_path(pid) else {
                continue;
            };
            let exe = exe_name(&path);
            if let Some(game) = self
                .games
                .iter()
                .find(|game| is_listed_exe(exe, game.process_names))
            {
                let label = format!("{exe}（{}）", game.display_name);
                return Ok(Some((
                    window,
                    SourceInfo::new(SourceKind::GameWindow, &label),
                )));
            }
        }
        Ok(None)
    }
}

impl FrameSource for GameWindowSource {
    fn next_frame(&mut self) -> Result<Frame, CaptureError> {
        if let Some((id, _)) = &self.found
            && let Some(window) = find_window(*id)?
        {
            return capture_window(&window);
        }
        // 还没找到，或者窗口关了：重新找。
        self.found = None;
        let (window, info) = self.search()?.ok_or(CaptureError::NotFound)?;
        self.found = Some((window.id().map_err(failed)?, info));
        capture_window(&window)
    }

    fn describe(&self) -> SourceInfo {
        match &self.found {
            Some((_, info)) => info.clone(),
            None => {
                let names: Vec<&str> = self.games.iter().map(|game| game.display_name).collect();
                SourceInfo::new(SourceKind::GameWindow, &names.join("、"))
            }
        }
    }
}

    pub fn new(target: &WindowTarget) -> Self {
        Self {
            id: target.id,
            info: SourceInfo::new(SourceKind::PickedWindow, &target.label),
        }
    }
}

impl FrameSource for PickedWindowSource {
    fn next_frame(&mut self) -> Result<Frame, CaptureError> {
        let window = find_window(self.id)?.ok_or(CaptureError::Gone)?;
        capture_window(&window)
    }

    fn describe(&self) -> SourceInfo {
        self.info.clone()
    }
}

/// 整个显示器。
pub struct MonitorSource {
    id: u32,
    info: SourceInfo,
}

impl MonitorSource {
    pub fn new(target: &MonitorTarget) -> Self {
        Self {
            id: target.id,
            info: SourceInfo::new(SourceKind::Monitor, &target.label),
        }
    }
}

impl FrameSource for MonitorSource {
    fn next_frame(&mut self) -> Result<Frame, CaptureError> {
        let monitor = Monitor::all()
            .map_err(failed)?
            .into_iter()
            .find(|monitor| monitor.id().ok() == Some(self.id))
            .ok_or(CaptureError::Gone)?;
        monitor.capture_image().map(to_frame).map_err(failed)
    }

    fn describe(&self) -> SourceInfo {
        self.info.clone()
    }
}

/// 按窗口句柄找回窗口。窗口关了（或者不再可见）就返回 None。
fn find_window(id: u32) -> Result<Option<Window>, CaptureError> {
    Ok(Window::all()
        .map_err(failed)?
        .into_iter()
        .find(|window| window.id().ok() == Some(id)))
}

/// 截窗口所在的那块屏幕区域。窗口最小化时返回 `Minimized`。
fn capture_window(window: &Window) -> Result<Frame, CaptureError> {
    if window.is_minimized().map_err(failed)? {
        return Err(CaptureError::Minimized);
    }
    let monitor = window.current_monitor().map_err(failed)?;
    let window_rect = Rect {
        x: window.x().map_err(failed)?,
        y: window.y().map_err(failed)?,
        width: window.width().map_err(failed)?,
        height: window.height().map_err(failed)?,
    };
    let monitor_rect = Rect {
        x: monitor.x().map_err(failed)?,
        y: monitor.y().map_err(failed)?,
        width: monitor.width().map_err(failed)?,
        height: monitor.height().map_err(failed)?,
    };
    let region = visible_region(window_rect, monitor_rect)
        .ok_or_else(|| CaptureError::Failed("窗口不在屏幕上".to_owned()))?;
    monitor
        .capture_region(region.x as u32, region.y as u32, region.width, region.height)
        .map(to_frame)
        .map_err(failed)
}

fn to_frame(image: RgbaImage) -> Frame {
    let (width, height) = image.dimensions();
    let luma = DynamicImage::ImageRgba8(image).into_luma8().into_raw();
    Frame {
        width,
        height,
        luma,
    }
}

fn failed(error: XCapError) -> CaptureError {
    CaptureError::Failed(error.to_string())
}

//! watch：自动截图识别登录二维码，发现后问你要不要登录（设计文档第 6.2、6.3 节）。

use std::collections::VecDeque;
use std::error::Error;
use std::io::{self, BufRead, Write};
use std::time::{Duration, Instant};

use mhy_carry_api::{ApiClient, ApiError, Credentials};
use mhy_carry_core::capture::FrameSource;
use mhy_carry_core::confirm::AlwaysAsk;
use mhy_carry_core::decode::RxingDecoder;

    Action, Event, Failure, Notice, Now, Observation, Prompt, ScanSession, ScanStatus, observe,

/// 每秒最多 4 帧（设计文档第 6.2 节）。

/// 自动模式下找不到游戏窗口时，每 2 秒重找一次。
const SEARCH_INTERVAL: Duration = Duration::from_secs(2);
/// 这么久没有新画面时喂一次 Tick，让会话检查超时。
const TICK: Duration = Duration::from_secs(1);

/// 命令行里的截图目标。
#[derive(Debug, Clone, Copy, clap::ValueEnum)]
pub enum Target {

    Auto,

    /// 整个显示器
    Monitor,

    fn from(target: Target) -> Self {
        match target {
            Target::Auto => TargetKind::Auto,
            Target::Window => TargetKind::Window,
            Target::Monitor => TargetKind::Monitor,
        }
    }

pub async fn run(target: Option<TargetKind>) -> CliResult {
    let ctx = Context::load()?;
    let file = ctx.store.load()?;
    let account = file
        .accounts
        .first()
        .ok_or("还没有绑定账号，先运行 mhy-carry-cli bind")?;
    let source = choose_source(target.unwrap_or(ctx.settings.scan.default_target))?;
    let credentials = Credentials {
        stoken: &account.stoken,
        mid: &account.mid,
    };

    let (mut session, first) = ScanSession::start(
        source.describe(),
        account.masked_uid(),
        Duration::from_secs(ctx.settings.scan.idle_timeout_secs),
        Box::new(AlwaysAsk),
        Now::current(),
    );
    println!("开始扫描，按 Ctrl+C 结束。");
    let mut printer = Printer::default();
    printer.show(session.status());

    let mut frames = spawn_capture(source);
    let mut actions = VecDeque::from([first]);
    loop {
        while let Some(action) = actions.pop_front() {
            let event = match action {
                Action::CheckCredential => {
                    Event::CredentialChecked(check_credential(&ctx.api, &credentials).await)
                }
                Action::Ask(request) => Event::Answered(ask(request).await?),
                Action::Login(qr) => Event::LoginFinished(
                    ctx.api
                        .login_with_qr(&qr, &credentials)
                        .await
                        .map_err(Failure::from),
                ),
                Action::Finish => return Ok(()),
            };
            actions.extend(session.handle(event, Now::current()));
            printer.show(session.status());
        }
        let event = match tokio::time::timeout(TICK, frames.recv()).await {
            Ok(Some(observation)) => Event::Observed(observation),
            Ok(None) => return Err("截图线程意外退出".into()),
            Err(_) => Event::Tick,
        };
        actions.extend(session.handle(event, Now::current()));
        printer.show(session.status());
    }
}

/// 按目标建好画面来源。选窗口、选显示器时在终端里列出来让你选。
fn choose_source(target: TargetKind) -> Result<Box<dyn FrameSource + Send>, Box<dyn Error>> {
    Ok(match target {
        TargetKind::Auto => Box::new(GameWindowSource::new(GAMES)),
        TargetKind::Window => {
            let windows = list_windows()?;
            if windows.is_empty() {
                return Err("没有可以选择的窗口".into());
            }
            println!("选择要扫描的窗口：");
            for (i, window) in windows.iter().enumerate() {
                println!("  {}. {}", i + 1, window.label);
            }
            let index = read_choice(windows.len(), None)?;
            Box::new(PickedWindowSource::new(&windows[index]))
        }
        TargetKind::Monitor => {
            let monitors = list_monitors()?;
            let primary = monitors.iter().position(|monitor| monitor.is_primary);
            let index = match monitors.len() {
                0 => return Err("没有找到显示器".into()),
                1 => 0,
                count => {
                    println!("选择要扫描的显示器（直接回车选主显示器）：");
                    for (i, monitor) in monitors.iter().enumerate() {
                        let mark = if monitor.is_primary { "（主显示器）" } else { "" };
                        println!("  {}. {}{mark}", i + 1, monitor.label);
                    }
                    read_choice(count, primary)?
                }
            };
            Box::new(MonitorSource::new(&monitors[index]))
        }
    })
}

/// 读一个 1 到 `count` 之间的序号，返回从 0 开始的下标。直接回车时用 `default`。
fn read_choice(count: usize, default: Option<usize>) -> io::Result<usize> {
    loop {
        print!("序号：");
        io::stdout().flush()?;
        let mut line = String::new();
        if io::stdin().lock().read_line(&mut line)? == 0 {
            return Err(io::Error::new(io::ErrorKind::UnexpectedEof, "没有输入"));
        }
        match parse_choice(&line, count, default) {
            Some(index) => return Ok(index),
            None => println!("请输入 1 到 {count} 之间的数字。"),
        }
    }
}

fn parse_choice(input: &str, count: usize, default: Option<usize>) -> Option<usize> {
    let input = input.trim();
    if input.is_empty() {
        return default;
    }
    match input.parse::<usize>() {
        Ok(number) if (1..=count).contains(&number) => Some(number - 1),
        _ => None,
    }
}

/// 在单独的线程里截图和识别（设计文档第 6.2 节第 2 步）。结果放进容量为 1 的通道，
/// 会话来不及处理时直接丢掉这一帧。主循环结束后通道关闭，线程跟着退出。
fn spawn_capture(mut source: Box<dyn FrameSource + Send>) -> mpsc::Receiver<Observation> {
    let (sender, receiver) = mpsc::channel(1);
    std::thread::spawn(move || {
        loop {
            let started = Instant::now();
            let observation = observe(source.as_mut(), &RxingDecoder);
            let interval = if observation == Observation::TargetMissing {
                SEARCH_INTERVAL
            } else {
                FRAME_INTERVAL
            };
            if let Err(mpsc::error::TrySendError::Closed(_)) = sender.try_send(observation) {
                return;
            }
            if let Some(rest) = interval.checked_sub(started.elapsed()) {
                std::thread::sleep(rest);
            }
        }
    });
    receiver
}

/// 检查凭证。它没有副作用，网络出错时重试一次（设计文档第 10 节）。
async fn check_credential(api: &ApiClient, credentials: &Credentials<'_>) -> Result<(), Failure> {
    match api.check_stoken(credentials).await {
        Err(ApiError::Network(_)) => api.check_stoken(credentials).await.map_err(Failure::from),
        result => result.map_err(Failure::from),
    }
}

/// 在终端里问你要不要登录。先响一声提示音，因为终端可能被游戏挡住。
async fn ask(request: Prompt) -> io::Result<bool> {
    let question = format!("\x07{}", request.question());
    tokio::task::spawn_blocking(move || prompt::confirm(&question))
        .await
        .map_err(io::Error::other)?
}

/// 状态有变化时打印一行，带时间；出现新的提示也打印一行。
#[derive(Default)]
struct Printer {
    last_line: Option<String>,
    last_notice: Option<Notice>,
}

impl Printer {
    fn show(&mut self, status: &ScanStatus) {
        match status {
            // 提问本身会打印出来；新的一次询问之后，同样的提示要能再打印一次。
            ScanStatus::AwaitingConfirm { .. } => {
                self.last_notice = None;
                return;
            }
            ScanStatus::LoggingIn => self.last_notice = None,
            _ => {}
        }
        let line = status.to_string();
        if self.last_line.as_ref() != Some(&line) {
            println!("[{}] {line}", now_hms());
            self.last_line = Some(line);
        }
        if let Some(notice) = status.notice()
            && self.last_notice.as_ref() != Some(notice)
        {
            println!("[{}] 提示：{notice}", now_hms());
            self.last_notice = Some(notice.clone());
        }
    }
}

fn now_hms() -> String {
    jiff::Zoned::now().strftime("%H:%M:%S").to_string()
}
