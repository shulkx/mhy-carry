# v0.2 多账号（M5）实施计划

> **给执行者：** 在当前会话里按顺序执行（executing-plans），不要每个任务开一个子代理。步骤用复选框（`- [x]`）跟踪。

**目标：** 支持绑定多个账号、选一个“使用中”的账号扫码登录、显示原神角色（昵称、等级、游戏 UID）和自己写的备注，发布 v0.2.0（设计文档第 6.4 节、第 13 节 M5）。

**做法：**
- `core`：账号文件升到格式 2，加上多账号的规则（添加或更新、解绑、使用中的账号、账号名称、备注清理）；`settings.json` 记使用中的账号。
- `api`：检查凭证时顺便拿回 `cookie_token`，再用它查原神官服角色。
- `runner`：检查凭证时把查到的角色交给界面。
- `cli`、`app`：改成多账号。界面按原型 `docs/design/ui-prototype-accounts.html` 做。

**技术栈：** 不新增依赖。

**设计文档：** [docs/design/2026-10-11-mhy-carry-design.md](../design/2026-10-11-mhy-carry-design.md) 第 6.1–6.4、8–11、13、14 节。

**执行记录（2026-10-14）：** 任务 1–11 已完成，等用户实测（任务 12）。和计划的差异：
- 任务 7、8 合并成一次提交：Rust 端改了状态快照的结构，单独提交的话，那一版的界面对不上。
- 计划里的测试个数有两处写错：account 的测试是 11 个；runner 里 `FakeApi::new(Ok(()))` 只有 2 处。
- 推送后 CI 的 cargo-deny 报了 rustls 0.23.45 的四条新公告（RUSTSEC-2026-0346 到 0349），升到 0.23.46。
- 独立审查后另外修了：
  - 命令行 `account --refresh`、`bind`、`account --remove` 在联网或等确认之后，改成重读账号文件、只改那一个账号。原来会把整份旧内容写回，覆盖这期间在应用里做的修改。
  - “切换账号”按钮上的“(n)”“▼”点了列表闪一下就关：点外面关弹出层的判断改用 `composedPath()`。
  - 改备注时收到新快照，输入不再被冲掉；输入法上屏时的回车不算保存。
  - 查原神角色最多等 5 秒，不再拖慢开始扫描。
  - `check_stoken` 按任意 JSON 读 data：`cookie_token` 的类型变了只是查不了角色，不会让凭证检查失败。
  - 绑定后查角色单独起任务，不会被下一次绑定连带中止；应用保存绑定的账号挪到模型锁里做。
  - 命令行 `watch` 查到的角色也存进账号文件；备注可以以“-”开头。

//! 账号文件 `accounts.json` 的数据结构和多账号的规则（设计文档第 6.4、8 节）。明文保存。

pub use secrecy::{ExposeSecret, SecretString};
use serde::{Deserialize, Serialize, Serializer};

use crate::text::printable;

/// 本程序写出的账号文件格式版本。格式 2（v0.2）比格式 1 多了 `game_role`；
/// 读到格式 1 的文件照常使用，下次写入时升级。
pub const ACCOUNT_FILE_FORMAT: u32 = 2;
/// 不加密。
pub const ENCRYPTION_NONE: &str = "none";
/// 备注最多这么多个字。
pub const MAX_NOTE_CHARS: usize = 20;

#[derive(Debug, Serialize, Deserialize)]
pub struct AccountFile {
    pub format: u32,
    pub encryption: String,
    /// 按绑定的先后排列。
    pub accounts: Vec<Account>,
}

impl AccountFile {
    pub fn empty() -> Self {
        Self {
            format: ACCOUNT_FILE_FORMAT,
            encryption: ENCRYPTION_NONE.to_owned(),
            accounts: Vec::new(),
        }
    }

    pub fn get(&self, id: &str) -> Option<&Account> {
        self.accounts.iter().find(|account| account.id == id)
    }

    pub fn get_mut(&mut self, id: &str) -> Option<&mut Account> {
        self.accounts.iter_mut().find(|account| account.id == id)
    }

    /// 使用中的账号：`active` 指向的账号；没设过或者它已经不在了，就用第一个。
    pub fn active(&self, active: Option<&str>) -> Option<&Account> {
        active
            .and_then(|id| self.get(id))
            .or_else(|| self.accounts.first())
    }

    /// 保存绑定成功的账号（设计文档第 6.1 节）。通行证 ID 已经在列表里，就只更新凭证和
    /// 绑定时间，备注和原神角色不变；否则加到末尾。
    pub fn upsert(&mut self, account: Account) -> Upserted {
        if let Some(existing) = self.accounts.iter_mut().find(|a| a.uid == account.uid) {
            existing.mid = account.mid;
            existing.stoken = account.stoken;
            existing.bound_at = account.bound_at;
            return Upserted {
                id: existing.id.clone(),
                added: false,
            };
        }
        let id = account.id.clone();
        self.accounts.push(account);
        Upserted { id, added: true }
    }

    /// 解绑一个账号，返回删掉的账号；没有这个账号时返回 None。
    pub fn remove(&mut self, id: &str) -> Option<Account> {
        let index = self.accounts.iter().position(|account| account.id == id)?;
        Some(self.accounts.remove(index))
    }
}

/// [`AccountFile::upsert`] 的结果。
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Upserted {
    /// 账号的本地 ID。
    pub id: String,
    /// 是新加的账号，而不是更新了已有账号的凭证。
    pub added: bool,
}

#[derive(Debug, Serialize, Deserialize)]
pub struct Account {
    /// 本地生成的 UUID，只用来区分账号。
    pub id: String,
    /// 米哈游通行证 ID，不是原神里的 UID。
    pub uid: String,
    pub mid: String,
    #[serde(serialize_with = "serialize_secret")]
    pub stoken: SecretString,
    /// 自己写的备注，可以为空（设计文档第 6.4 节）。
    #[serde(default)]
    pub note: String,
    pub bound_at: jiff::Timestamp,
    /// 查到的原神官服角色。格式 1 的文件里没有这一项；还没查到时是 None。
    #[serde(default)]
    pub game_role: Option<GameRole>,
}

/// 原神官服的角色（设计文档第 6.4 节）。不是凭证。
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct GameRole {
    pub nickname: String,
    pub level: u32,
    /// 原神里的 UID。
    pub game_uid: String,
}

impl Account {
    pub fn new(uid: String, mid: String, stoken: SecretString, bound_at: jiff::Timestamp) -> Self {
        Self {
            id: uuid::Uuid::new_v4().to_string(),
            uid,
            mid,
            stoken,
            note: String::new(),
            bound_at,
            game_role: None,
        }
    }

    /// 账号名称：备注 → 原神昵称 → 通行证 ID，取第一个有值的。
    pub fn display_name(&self) -> String {
        if !self.note.is_empty() {
            return self.note.clone();
        }
        match &self.game_role {
            Some(role) if !role.nickname.is_empty() => role.nickname.clone(),
            _ => self.uid.clone(),
        }
    }

    /// 确认框里怎么称呼这个账号（设计文档第 6.2 节第 5 步），比如
    /// `账号「大号」（原神 UID 100000001，通行证 300012345）`。
    /// 既没有备注也没查到原神角色时，名称就是通行证 ID，写成 `通行证 300012345 的账号`。
    pub fn describe(&self) -> String {
        match (&self.game_role, self.note.is_empty()) {
            (None, true) => format!("通行证 {} 的账号", self.uid),
            (None, false) => format!("账号「{}」（通行证 {}）", self.note, self.uid),
            (Some(role), _) => format!(
                "账号「{}」（原神 UID {}，通行证 {}）",
                self.display_name(),
                role.game_uid,
                self.uid
            ),
        }
    }
}

/// 清理备注：控制字符和看不见的字符换成空格、去掉首尾空白，最多 [`MAX_NOTE_CHARS`] 个字。
pub fn normalize_note(input: &str) -> String {
    let cleaned: String = printable(input).chars().take(MAX_NOTE_CHARS).collect();
    cleaned.trim_end().to_owned()
}

fn serialize_secret<S: Serializer>(
    secret: &SecretString,
    serializer: S,
) -> Result<S::Ok, S::Error> {
    serializer.serialize_str(secret.expose_secret())
}

    /// `cookie_token` 来自 [`ApiClient::check_stoken`]。
    pub async fn genshin_role(
        &self,
        account_id: &str,
        cookie_token: &SecretString,

        headers.insert(REFERER, HeaderValue::from_static("https://act.mihoyo.com/"));
        let data: RoleList = self.get_json(url, headers).await?.into_data()?;

        })

        uid: Option<&str>,
    ) -> Result<&'a Account, Box<dyn Error>> {
        match uid {

                .accounts

async fn refresh(ctx: &Context) -> CliResult {

impl AccountsView {
    /// 从读账号文件的结果得出账号列表。`active` 是设置里记的使用中的账号，
    /// `credentials` 是这次运行里查过的凭证状态。
    pub fn from_load(
        result: Result<AccountFile, StoreError>,
        active: Option<&str>,
        credentials: &HashMap<String, Credential>,
    ) -> Self {
        match result {
            Ok(file) => match file.active(active) {
                Some(current) => AccountsView::List {
                    active: current.id.clone(),
                    items: file
                        .accounts
                        .iter()
                        .map(|account| AccountItem::new(account, credentials))
                        .collect(),
                },
                None => AccountsView::None { notice: None },
            },
            Err(error @ StoreError::Corrupt { .. }) => AccountsView::None {
                notice: Some(error.to_string()),
            },
            Err(error) => AccountsView::Unavailable {
                message: error.to_string(),
            },
        }
    }

    /// 列表里有没有这个账号。
    pub fn contains(&self, id: &str) -> bool {
        matches!(self, AccountsView::List { items, .. } if items.iter().any(|item| item.id == id))

            && let Some(item) = items.iter_mut().find(|item| item.id == id)
        {
            item.credential = credential;
        }
    }
}

/// 账号凭证的状态。只在开始扫描和绑定成功时检查，打开程序时不联网。
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize)]
#[serde(rename_all = "snake_case")]
pub enum Credential {
    Unchecked,
    Valid,
    Invalid,
}

/// 扫描状态变化后，凭证状态跟着变：过了检查凭证这一步就是有效；结束原因是凭证失效就是已失效。
pub fn credential_after(status: &ScanStatus) -> Option<Credential> {
    match status {
        ScanStatus::Idle {
            last: Some(StopReason::CredentialInvalid),
        } => Some(Credential::Invalid),
        ScanStatus::Idle { .. } | ScanStatus::CheckingCredential => None,
        _ => Some(Credential::Valid),
    }
}

/// 记下提示出现的时间（设计文档第 6.3 节“最近一条提示，带时间”）。
/// 只有提示的内容变了才更新时间；暂停、等你确认时提示暂时不显示，不算变化。
pub fn track_notice(
    last: &mut Option<String>,
    at: &mut Option<String>,
    status: &ScanStatus,
    now: impl FnOnce() -> String,
) {
    if let Some(notice) = status.notice() {
        let text = notice.to_string();
        if last.as_deref() != Some(text.as_str()) {
            *last = Some(text);
            *at = Some(now());
        }
    }
}

    /// 账号相关的操作只能在空闲时做：扫描中、绑定中都不行，账号文件读不了时也不行
    /// （设计文档第 9 节）。

            return Err(message.clone());
        }
        Ok(())

/// 交给 Tauri 管理的共享状态。
pub struct Shared {
    model: Mutex<Model>,
    pub store: JsonFileStore,
    pub settings_path: PathBuf,
    pub api: ApiClient,
}

impl Shared {
    /// 启动时读取设置和账号文件。打开程序时不联网（设计文档第 6.3 节）。
    pub fn load() -> Result<Self, Box<dyn Error>> {
        let settings_path = paths::settings_path()?;
        let settings = Settings::load_or_init(&settings_path)?;
        let store = JsonFileStore::new(paths::accounts_path()?);
        let api = ApiClient::new(settings.device_id.clone())?;
        let mut model = Model {
            accounts: AccountsView::None { notice: None },
            credentials: HashMap::new(),
            bind: BindView::Idle,
            scan: ScanStatus::Idle { last: None },
            scan_account: None,
            settings,
            leftovers: 0,
            bind_task: None,
            scan_stop: None,
            last_notice: None,
            notice_at: None,
            seq: 0,
            last_sent: None,
        };
        reload_accounts(&mut model, &store);
        Ok(Self {
            model: Mutex::new(model),
            store,
            settings_path,
            api,
        })
    }

    pub fn lock(&self) -> MutexGuard<'_, Model> {
        // 锁只在同步代码里短暂持有；万一中毒了，照常用里面的数据。
        self.model
            .lock()
            .unwrap_or_else(|poisoned| poisoned.into_inner())
    }

    pub fn snapshot(&self) -> AppState {
        snapshot_of(&self.lock(), &self.store)
    }
}

fn snapshot_of(model: &Model, store: &JsonFileStore) -> AppState {
    AppState {
        seq: model.seq,
        accounts: model.accounts.clone(),
        bind: model.bind.clone(),
        scan: model.scan.clone(),
        scan_text: model.scan.to_string(),
        notice_text: model.scan.notice().map(ToString::to_string),
        notice_at: model.notice_at.clone(),
        settings: SettingsView {
            default_target: model.settings.scan.default_target,
            idle_timeout_secs: model.settings.scan.idle_timeout_secs,
        },
        credential_file: store.path().display().to_string(),
        leftovers: model.leftovers,
    }
}

/// 修改状态，有变化就把新的完整快照推送给界面。
///
/// 后台任务的推送要先排进事件循环，命令里的推送立刻发出，两者到达界面的顺序可能和生成
/// 顺序相反。所以每份新快照都带递增的序号，界面丢掉比手上旧的快照。
pub fn update(app: &AppHandle, change: impl FnOnce(&mut Model)) {
    let shared = app.state::<Shared>();
    let snapshot = {
        let mut model = shared.lock();
        change(&mut model);
        // 序号还没加，内容一样就和上一份完全相同，不用推送。
        let mut snapshot = snapshot_of(&model, &shared.store);
        if model.last_sent.as_ref() == Some(&snapshot) {
            return;
        }
        model.seq += 1;
        snapshot.seq = model.seq;
        model.last_sent = Some(snapshot.clone());
        snapshot
    };
    let _ = app.emit(STATE_EVENT, snapshot);
}

/// 重新读账号文件，刷新账号列表和残留文件数。
pub fn reload_accounts(model: &mut Model, store: &JsonFileStore) {
    model.accounts = AccountsView::from_load(
        store.load(),
        model.settings.active_account.as_deref(),
        &model.credentials,
    );
    model.leftovers = store.leftover_files().map_or(0, |files| files.len());
}

/// 把查到的原神角色存进账号文件，再刷新账号列表。写不进去也不影响使用，下次查到时再存
/// （设计文档第 6.4 节）。
pub fn save_role(model: &mut Model, store: &JsonFileStore, id: &str, role: &GameRole) {
    if let Ok(mut file) = store.load()
        && let Some(account) = file.get_mut(id)
        && account.game_role.as_ref() != Some(role)
    {
        account.game_role = Some(role.clone());
        let _ = store.save(&file);
    }
    reload_accounts(model, store);
}

#[tauri::command(rename_all = "snake_case")]
pub async fn scan_start(app: AppHandle, target: TargetKind, id: Option<u32>) -> CommandResult {
    let (stop, stop_signal) = mpsc::channel(1);
    let (idle_timeout, active) = {
        let shared = app.state::<Shared>();
        let mut model = shared.lock();
        if model.scanning() {
            return Ok(());
        }
        if model.bind.in_progress() {
            return Err("绑定中不能开始扫描。".to_owned());
        }
        model.scan_stop = Some(stop);
        model.last_notice = None;
        model.notice_at = None;
        (

        )
    };

            scan::spawn(app, job, stop_signal);
            Ok(())
        }
        Err(message) => {
            update(&app, |model| model.scan_stop = None);
            Err(message)
        }
    }
}

fn prepare_job(
    app: &AppHandle,
    target: TargetKind,
    id: Option<u32>,
    idle_timeout: Duration,
    active: Option<&str>,
) -> CommandResult<(ScanJob, String)> {
    let shared = app.state::<Shared>();
    let mut file = shared.store.load().map_err(|error| error.to_string())?;
    let account_id = file
        .active(active)
        .map(|account| account.id.clone())
        .ok_or("还没有绑定账号，先用米游社扫码绑定。")?;
    let account = file.remove(&account_id).ok_or(ACCOUNT_GONE)?;
    let source: Box<dyn FrameSource + Send> = match target {
        TargetKind::Auto => Box::new(GameWindowSource::new(GAMES)),
        TargetKind::Window => {
            let id = id.ok_or("先选择要扫描的窗口。")?;
            let window = list_windows()
                .map_err(|error| error.to_string())?
                .into_iter()
                .find(|window| window.id == id)
                .ok_or("这个窗口已经不在了，请刷新列表。")?;
            Box::new(PickedWindowSource::new(&window))
        }
        TargetKind::Monitor => {
            let id = id.ok_or("先选择要扫描的显示器。")?;
            let monitor = list_monitors()
                .map_err(|error| error.to_string())?
                .into_iter()
                .find(|monitor| monitor.id == id)
                .ok_or("这个显示器已经不在了，请刷新列表。")?;
            Box::new(MonitorSource::new(&monitor))
        }
    };
    let job = ScanJob {
        source,
        decoder: Box::new(RxingDecoder),
        account: account.describe(),
        uid: account.uid,
        mid: account.mid,
        stoken: account.stoken,
        idle_timeout,
    };
    Ok((job, account_id))
}

//! 绑定账号：用米游社 App 扫码（设计文档第 6.1 节）。绑定的账号加进列表（已经在列表里就只
//! 更新凭证），设为使用中，再查一次原神角色（第 6.4 节）。

use std::time::Duration;

use mhy_carry_api::{ApiError, BindStatus, Credentials, retcode};
use mhy_carry_core::account::{Account, AccountFile, Upserted};
use mhy_carry_core::store::{AccountStore, StoreError};
use mhy_carry_runner::LoginApi;
use tauri::{AppHandle, Manager};

use crate::model::{Shared, reload_accounts, save_role, update};
use crate::state::{BindView, Credential, qr_data_uri};

const POLL_INTERVAL: Duration = Duration::from_secs(2);
/// 查询状态没有副作用，网络出错允许重试一次，连续两次就放弃（设计文档第 10 节）。
const MAX_NETWORK_ERRORS_IN_A_ROW: u32 = 2;
/// “绑定成功”显示这么久后自动收起（设计文档第 6.3 节）。
const SUCCESS_SHOWN_FOR: Duration = Duration::from_secs(5);

/// 跑完一次绑定，把结果写进状态。
pub async fn run(app: AppHandle) {
    let shared = app.state::<Shared>();
    let saved = match bind(&app).await {
        Ok(saved) => saved,
        Err(outcome) => {
            update(&app, |model| {
                // 已经被取消了就不再显示结果。
                if model.bind.in_progress() {
                    model.bind = outcome;
                }
            });
            return;
        }
    };
    update(&app, |model| {
        // 绑定成功的账号设为使用中。设置写不进去只影响下次启动时默认用哪个账号。
        model.settings.active_account = Some(saved.id.clone());
        let _ = model.settings.save(&shared.settings_path);
        // 刚拿到的凭证一定有效。
        model.credentials.insert(saved.id.clone(), Credential::Valid);
        reload_accounts(model, &shared.store);
        if model.bind.in_progress() {
            model.bind = BindView::Succeeded { added: saved.added };
        }
    });
    fetch_role(&app, &saved.id).await;
    // 成功时账号已经显示出来，提示几秒后收起；过期、取消、失败要你处理，一直显示。
    tokio::time::sleep(SUCCESS_SHOWN_FOR).await;
    update(&app, |model| {
        if matches!(model.bind, BindView::Succeeded { .. }) {
            model.bind = BindView::Idle;
        }
    });
}

/// 查一次原神角色，查到就存进账号文件。查不到不提示（设计文档第 6.4 节）。
async fn fetch_role(app: &AppHandle, id: &str) {
    let shared = app.state::<Shared>();
    let Ok(file) = shared.store.load() else {
        return;
    };
    let Some(account) = file.get(id) else {
        return;
    };
    let credentials = Credentials {
        stoken: &account.stoken,
        mid: &account.mid,
    };
    if let Ok(Some(role)) = shared.api.check_credential(&account.uid, &credentials).await {
        update(app, |model| save_role(model, &shared.store, id, &role));
    }
}

async fn bind(app: &AppHandle) -> Result<Upserted, BindView> {
    let shared = app.state::<Shared>();
    let qr = shared
        .api
        .create_bind_qr()
        .await
        .map_err(|error| BindView::Failed {
            message: error.to_string(),
        })?;
    let image = qr_data_uri(&qr.url).map_err(|error| BindView::Failed {
        message: format!("生成二维码失败：{error}"),
    })?;
    // 取消只在下一个 await 处生效；这期间已经取消了，就不要把状态改回“进行中”。
    update(app, |model| {
        if model.bind.in_progress() {
            model.bind = BindView::WaitingScan { qr: image.clone() };
        }
    });

    let mut network_errors = 0;
    loop {
        tokio::time::sleep(POLL_INTERVAL).await;
        match shared.api.query_bind_qr(&qr.ticket).await {
            Ok(BindStatus::Created) => network_errors = 0,
            Ok(BindStatus::Scanned) => {
                network_errors = 0;
                update(app, |model| {
                    if model.bind.in_progress() {
                        model.bind = BindView::WaitingConfirm { qr: image.clone() };
                    }
                });
            }
            Ok(BindStatus::Confirmed(bound)) => {
                let account =
                    Account::new(bound.uid, bound.mid, bound.stoken, jiff::Timestamp::now());
                return save(&shared, account).map_err(|message| BindView::Failed { message });
            }
            Err(ApiError::Network(_)) if network_errors + 1 < MAX_NETWORK_ERRORS_IN_A_ROW => {
                network_errors += 1;
            }
            Err(error) if error.retcode() == Some(retcode::QR_EXPIRED) => {
                return Err(BindView::Expired);
            }
            Err(error) if error.retcode() == Some(retcode::QR_CANCELLED) => {
                return Err(BindView::Cancelled);
            }
            Err(error) => {
                return Err(BindView::Failed {
                    message: error.to_string(),
                });
            }
        }
    }
}

/// 保存账号：新的通行证加到列表末尾，已有的只更新凭证（设计文档第 6.1 节）。
fn save(shared: &Shared, account: Account) -> Result<Upserted, String> {
    let mut file = match shared.store.load() {
        Ok(file) => file,
        // 损坏的文件已经改名备份了，从空文件开始。
        Err(StoreError::Corrupt { .. }) => AccountFile::empty(),
        Err(error) => return Err(error.to_string()),
    };
    let saved = file.upsert(account);
    shared
        .store
        .save(&file)
        .map_err(|error| error.to_string())?;
    Ok(saved)
}

/// 在 Rust 端弹出系统确认框（网页端没有对话框权限，设计文档第 9 节）。
///
/// 登录确认（`topmost`）不挂在主窗口下面：主窗口可能最小化了，挂在它下面的确认框会
/// 跟着隐藏；同时闪烁主窗口的任务栏按钮。解绑、删除旧文件的确认挂在主窗口下面。
pub async fn confirm(app: &AppHandle, text: String, topmost: bool) -> bool {
    let main = app
        .get_webview_window("main")
        .and_then(|window| window.hwnd().ok())
        .map(|hwnd| hwnd.0 as isize);
    let owner = if topmost { None } else { main };
    if topmost && let Some(main) = main {
        dialog::flash(main);
    }
    tauri::async_runtime::spawn_blocking(move || dialog::confirm(owner, &text, topmost))
        .await
        .unwrap_or(false)
}

    box.append(actions);
  } else {
    box.append(renderCard(activeAccount()));
  }

  if (open === "switch" && accountList().length > 1) box.append(renderSwitcher());
  if (bind.kind === "succeeded") {
    // 几秒后由 Rust 端自动收起。
    box.append(el("div", { class: "message ok" },
      bind.added ? "已添加账号，并设为使用中。" : "已更新这个账号的凭证，并设为使用中。"));
  }
  if (state.leftovers > 0) {
    // 账号文件损坏时留下的备份里可能有明文凭证，单独删除（设计文档第 6.4 节）。
    const actions = el("div", { class: "actions" });
    const remove = button("删除旧账号文件", "btn danger", () => call("delete_leftovers"));
    remove.disabled = state.scan.kind !== "idle";
    actions.append(remove);
    box.append(actions);
  }
}

function renderCard(item) {
  const card = el("div", { class: "card" + (item.credential === "invalid" ? " invalid" : "") });
  const main = el("div", { class: "card-main" });
  if (editing) {
    main.append(renderNoteEditor(item));
  } else {
    const title = el("div", { class: "card-title" });
    title.append(el("span", { class: "name" }, item.name));
    if (item.role) title.append(level(item));
    main.append(title);
    // 名称用的是备注时，下面补一行原神昵称。
    if (item.note && item.role) main.append(el("div", { class: "card-sub" }, "原神昵称 " + item.role.nickname));
  }

  const chips = el("div", { class: "chips" });
  for (const [label, value] of [["原神 UID", item.role?.game_uid], ["通行证", item.passport_id]]) {
    const chip = el("span", { class: "chip" });
    chip.append(el("span", { class: "k" }, label),
      el("span", { class: "v" + (value ? "" : " missing") }, value ?? "未查到"));
    chips.append(chip);
  }

  const side = el("div", { class: "card-side" });
  const more = button("⋯", "more", () => {
    open = open === "menu" ? null : "menu";
    renderAccount();
  }, { "aria-label": "更多操作", "aria-haspopup": "menu", "aria-expanded": String(open === "menu") });
  more.disabled = accountsLocked();
  side.append(el("span", { class: "cred " + item.credential }, CREDENTIAL_LABELS[item.credential]), more);

  card.append(avatar(item), main, side, chips);
  if (open === "menu") card.append(renderMenu(item));
  return card;
}

function renderNoteEditor(item) {
  const box = el("div", { class: "name-edit" });
  const input = el("input", {
    type: "text", id: "note-input", maxlength: String(MAX_NOTE_CHARS),
    "aria-label": "备注", placeholder: "备注，比如“大号”",
  });
  input.value = item.note;
  input.addEventListener("keydown", (event) => {
    if (event.key === "Enter") {
      editing = false;
      call("set_note", { id: item.id, note: input.value });
      renderAccount();
    } else if (event.key === "Escape") {
      editing = false;
      renderAccount();
    }
  });
  box.append(input, el("div", { class: "hint" }, "回车保存，Esc 取消；最多 " + MAX_NOTE_CHARS + " 个字"));
  queueMicrotask(() => input.focus());
  return box;
}

function renderMenu(item) {
  const menu = el("div", { class: "popover menu", role: "menu" });
  const items = [
    button("编辑备注", "", () => {
      open = null;
      editing = true;
      renderAccount();
    }, { role: "menuitem" }),
    button("重新绑定", "", () => startBind(item.passport_id), { role: "menuitem" }),
    button("解绑", "danger", () => {
      open = null;
      renderAccount();
      call("unbind", { id: item.id });
    }, { role: "menuitem" }),
  ];
  // 凭证失效的账号最常用的是重新绑定，排到第一项。
  if (item.credential === "invalid") items.unshift(items.splice(1, 1)[0]);
  menu.append(...items);
  return menu;
}

function renderSwitcher() {
  const list = accountList();
  const box = el("div", { class: "popover switcher" });
  const rows = el("div", { class: "switcher-list", role: "listbox", "aria-label": "切换使用中的账号" });
  for (const item of list) {
    const selected = item.id === state.accounts.active;
    const row = button("", "switch-row", () => {
      open = null;
      if (!selected) call("set_active", { id: item.id });
      renderAccount();
    }, { role: "option", "aria-selected": String(selected) });
    const title = el("span", { class: "row-title" });
    title.append(el("span", {}, item.name));
    if (item.role) title.append(level(item));
    row.append(el("span", { class: "check", "aria-hidden": "true" }, selected ? "✓" : ""), avatar(item, true), title,
      el("span", { class: "cred " + item.credential }, SHORT_CREDENTIAL[item.credential]),
      el("span", { class: "row-id" }, item.role ? "原神 UID " + item.role.game_uid : "通行证 " + item.passport_id));
    rows.append(row);
  }
  box.append(rows, el("div", { class: "switcher-foot" },
    "共 " + list.length + " 个账号。要编辑或解绑某个账号，先切换到它，再用卡片上的“⋯”。"));
  return box;
}

function renderBind(box, bind) {
  const close = () => call("bind_cancel");
  const actions = el("div", { class: "actions" });
  if (bind.kind === "waiting_scan" || bind.kind === "waiting_confirm") {
    const wrap = el("div", { class: "bind" });
    wrap.append(el("img", { src: bind.qr, alt: "绑定用的二维码" }));
    const side = el("div");
    let [step, hint] = bind.kind === "waiting_scan"
      ? ["用米游社 App 扫描左边的二维码", "扫码时登录的是哪个账号，就添加哪个。扫码后在手机上确认。"]
      : ["已扫码，请在手机上确认", "确认后自动保存账号。"];
    if (rebindFor && bind.kind === "waiting_scan") hint = "请先在米游社 App 里登录通行证 " + rebindFor + "，再扫码。";
    side.append(el("div", { class: "step" }, step), el("div", { class: "meta" }, hint));
    actions.append(button("取消", "btn", close));
    side.append(actions);
    wrap.append(side);
    box.append(wrap);
    return;
  }
  const texts = {
    requesting: ["正在获取二维码…", "message"],
    expired: ["二维码已过期。", "message bad"],
    cancelled: ["已在手机上取消。", "message bad"],
    failed: ["绑定失败：" + (bind.message ?? ""), "message bad"],
  };
  const [text, className] = texts[bind.kind];
  box.append(el("div", { class: className }, text));
  if (bind.kind === "requesting") {
    actions.append(button("取消", "btn", close));
  } else {
    actions.append(button(bind.kind === "expired" ? "刷新" : "重新绑定", "btn primary", () => startBind(rebindFor)),
      button("关闭", "btn", close));
  }
  box.append(actions);
}

// ---- 扫描 ----

function dotClass(scan) {
  if (scan.kind === "scanning" || scan.kind === "logging_in") return "scanning";
  if (WAITING.includes(scan.kind)) return "waiting";
  if (scan.kind === "idle" && scan.last) {
    if (scan.last.kind === "logged_in") return "ok";
    if (BAD_STOPS.includes(scan.last.kind)) return "bad";
  }
  return "";
}

async function loadTargets(kind) {
  // 先记下原来的选择再清空列表，否则刷新后就丢了。
  const keep = $("target-select").value;
  targetList = [];
  fillTargets(keep);
  if (kind === "auto") return;
  targetList = (await call("list_targets", { kind })) ?? [];
  fillTargets(keep);
}

function fillTargets(keep) {
  const select = $("target-select");
  select.replaceChildren(...targetList.map((item) => el("option", { value: String(item.id) }, item.label)));
  // 刷新后保留原来的选择；没选过时选游戏窗口或主显示器。
  const preferred = targetList.find((item) => item.preferred);
  if (targetList.some((item) => String(item.id) === keep)) select.value = keep;
  else if (preferred) select.value = String(preferred.id);
}

function renderScan() {
  const scan = state.scan;
  const idle = scan.kind === "idle";
  const chosen = currentTarget();
  for (const name of TARGETS) {
    const node = $("target-" + name);
    node.setAttribute("aria-pressed", String(name === chosen));
    node.disabled = !idle;
  }
  $("target-pick").hidden = chosen === "auto";
  $("target-select").disabled = !idle;
  $("target-refresh").disabled = !idle;

  const start = $("scan-button");
  const active = activeAccount();
  if (idle) {
    // 大按钮写着扫描用的账号（设计文档第 6.3 节）。
    const ready = active && active.credential !== "invalid" && !BUSY_BIND.includes(state.bind.kind);
    start.textContent = active ? "开始扫描（" + active.name + "）" : "开始扫描";
    start.disabled = !ready;
  } else {
    start.textContent = "停止";
    // 登录请求已经发出，要等结果出来。
    start.disabled = scan.kind === "logging_in";
  }

  $("status-dot").className = "dot " + dotClass(scan);
  $("status-text").textContent = state.scan_text;
  const notice = $("status-notice");
  notice.replaceChildren();
  if (state.notice_text) {
    notice.append(el("time", {}, state.notice_at ?? ""), "提示：" + state.notice_text);
  } else if (idle && state.accounts.kind !== "list") {
    notice.textContent = "绑定账号后才能开始扫描。";
  }
}

function renderSettings() {
  const select = $("setting-target");
  const input = $("setting-timeout");
  if (document.activeElement !== select) select.value = state.settings.default_target;
  if (document.activeElement !== input) input.value = String(state.settings.idle_timeout_secs);
}

function saveSettings() {
  call("update_settings", {
    default_target: $("setting-target").value,
    idle_timeout_secs: Math.max(30, Math.round(Number($("setting-timeout").value)) || 300),
  });
}

function renderFooter() {
  const footer = $("footer");
  footer.replaceChildren("凭证明文保存在 ", el("code", {}, state.credential_file), "，解绑某个账号会删除它的凭证。");
  if (state.leftovers > 0) {
    footer.append(el("div", {}, "另有 " + state.leftovers + " 个旧账号文件（账号文件损坏时留下的备份），可以点上面的“删除旧账号文件”删掉。"));
  }
}

function render(next) {
  // 推送可能乱序到达，丢掉比手上旧的快照。
  if (state && next.seq < state.seq) return;
  state = next;
  renderAccount();
  renderScan();
  renderSettings();
  renderFooter();
}
