# MhyCarry M3 实现计划：Tauri 应用

> **For agentic workers:** REQUIRED SUB-SKILL: Use executing-plans to implement this plan task-by-task（按 CLAUDE.md，在当前会话里按顺序执行，不要每个任务开一个子代理）. Steps use checkbox (`- [x]`) syntax for tracking.

**目标：** 做出 MhyCarry 的图形界面：一个 440×640 的窗口，按设计文档第 6.3 节显示账号、绑定、扫描三块状态；登录确认用置顶的系统确认框；网页端只能调用我们自己的命令。达到设计文档第 13 节的 M3 验收标准：第 11 节手动检查清单全部通过，网页端调用不到对话框、文件等能力。

**架构：**
- 新增 `crates/runner`：把 `cli watch` 里的扫描运行循环抽出来，命令行和图形界面共用；区别只在怎么提问、怎么显示（`ScanUi`），接口调用也抽成 `LoginApi`，方便用假实现测试。
- `platform` 加 `dialog`：Windows `MessageBoxW` 确认框（置顶、默认按钮“否”）和任务栏闪烁。
- 新增 `app/src-tauri`（包名 `mhy-carry`）：Rust 端维护全部状态，有变化就推送完整快照 `state-changed`；网页端（`app/ui`，纯 HTML/CSS/JS）只按快照显示。
- 不装 tauri CLI：配置了 `frontendDist` 后，`cargo run -p mhy-carry` 会把 `app/ui` 嵌进程序。打包放到 M4。

**技术栈：** 新增 tauri 2.12（`withGlobalTauri`，不用 npm）、tauri-build 2.7、base64 0.22（绑定二维码的 data URI）。qrcode 在 app 里打开 `svg` 功能。

**设计文档：** [docs/design/2026-10-11-mhy-carry-design.md](../design/2026-10-11-mhy-carry-design.md)，重点是第 6.1、6.2、6.3、9、11 节；界面原型是 [docs/design/ui-prototype.html](../design/ui-prototype.html)。

```rust
//! Windows 系统确认框（设计文档第 6.2 节第 5 步、第 9 节）。网页端没有对话框权限，
//! 确认框只能从 Rust 端弹出。

use std::ffi::c_void;

use windows::Win32::Foundation::HWND;
use windows::Win32::UI::WindowsAndMessaging::{
    FLASHW_ALL, FLASHW_TIMERNOFG, FLASHWINFO, FlashWindowEx, IDYES, MB_DEFBUTTON2, MB_ICONWARNING,
    MB_SETFOREGROUND, MB_TOPMOST, MB_YESNO, MESSAGEBOX_STYLE, MessageBoxW,
};
use windows::core::HSTRING;

const TITLE: &str = "MhyCarry";

/// 弹出“是 / 否”确认框，阻塞到你回答为止，返回你是否点了“是”。
///
/// 默认按钮是“否”：确认框突然弹出时误按回车或空格只会取消。带警告图标，弹出时会响
/// 系统提示音。`topmost` 为真时置顶并尝试切到前台，用于登录确认：发现二维码时游戏
/// 在最前面，不置顶就会被挡住。`owner` 是所属窗口的句柄，确认框显示在它前面。
pub fn confirm(owner: Option<isize>, text: &str, topmost: bool) -> bool {
    let owner = owner.map(|raw| HWND(raw as *mut c_void));
    // SAFETY: 两个字符串在调用期间一直有效，MessageBoxW 只读取它们。
    let answer = unsafe {
        MessageBoxW(
            owner,
            &HSTRING::from(text),
            &HSTRING::from(TITLE),
            style(topmost),
        )
    };
    answer == IDYES
}

/// 闪烁窗口在任务栏上的按钮，直到窗口回到前台。
pub fn flash(window: isize) {
    let info = FLASHWINFO {
        cbSize: size_of::<FLASHWINFO>() as u32,
        hwnd: HWND(window as *mut c_void),
        dwFlags: FLASHW_ALL | FLASHW_TIMERNOFG,
        uCount: 0,
        dwTimeout: 0,
    };
    // SAFETY: info 在调用期间一直有效，系统只读取它；句柄无效时调用只是失败。
    unsafe {
        let _ = FlashWindowEx(&info);
    }
}

fn style(topmost: bool) -> MESSAGEBOX_STYLE {
    let style = MB_YESNO | MB_ICONWARNING | MB_DEFBUTTON2;
    if topmost {
        style | MB_TOPMOST | MB_SETFOREGROUND
    } else {
        style
    }
}
```

```rust
//! 扫码会话的运行循环（设计文档第 6.2、6.3 节）：截图线程、主循环、执行会话的动作。
//! 命令行（`cli watch`）和图形界面（`app`）共用，区别只在怎么提问、怎么显示状态（[`ScanUi`]）。
#![forbid(unsafe_code)]

use std::collections::VecDeque;
use std::future::Future;
use std::sync::Arc;
use std::sync::atomic::{AtomicBool, Ordering};
use std::time::{Duration, Instant};

use mhy_carry_api::{ApiClient, ApiError, Credentials};
use mhy_carry_core::account::SecretString;
use mhy_carry_core::capture::FrameSource;
use mhy_carry_core::confirm::AlwaysAsk;
use mhy_carry_core::decode::QrDecoder;
use mhy_carry_core::qr::LoginQr;
use mhy_carry_core::scan::{
    Action, Event, Failure, Now, Observation, Prompt, ScanSession, ScanStatus, observe,
};
use tokio::sync::mpsc;

/// 每秒最多 4 帧（设计文档第 6.2 节）。
const FRAME_INTERVAL: Duration = Duration::from_millis(250);
/// 自动模式下找不到游戏窗口时，每 2 秒重找一次。
const SEARCH_INTERVAL: Duration = Duration::from_secs(2);
/// 这么久没有新画面时喂一次 Tick，让会话检查超时。
const TICK: Duration = Duration::from_secs(1);

/// 怎么提问、怎么显示状态。命令行打印到终端；图形界面弹系统确认框、推送状态快照。
pub trait ScanUi: Sync {
    /// 每处理完一个事件调用一次，状态不一定有变化。
    fn show(&self, status: &ScanStatus);
    /// 问你要不要登录，返回 true 表示登录。
    fn ask(&self, prompt: Prompt) -> impl Future<Output = bool> + Send;
}

/// 检查凭证和扫码登录（设计文档第 5 节的 `LoginApi`）。正式实现是 [`ApiClient`]。
pub trait LoginApi: Sync {
    fn check_credential(
        &self,
        credentials: &Credentials<'_>,
    ) -> impl Future<Output = Result<(), Failure>> + Send;
    fn login(
        &self,
        qr: &LoginQr,
        credentials: &Credentials<'_>,
    ) -> impl Future<Output = Result<(), Failure>> + Send;
}

impl LoginApi for ApiClient {
    async fn check_credential(&self, credentials: &Credentials<'_>) -> Result<(), Failure> {
        // 检查凭证没有副作用，网络出错时重试一次（设计文档第 10 节）。
        match self.check_stoken(credentials).await {
            Err(ApiError::Network(_)) => self.check_stoken(credentials).await.map_err(Failure::from),
            result => result.map_err(Failure::from),
        }
    }

    async fn login(&self, qr: &LoginQr, credentials: &Credentials<'_>) -> Result<(), Failure> {
        self.login_with_qr(qr, credentials)
            .await
            .map_err(Failure::from)
    }
}

/// 一次扫描要用到的东西。
pub struct ScanJob {
    pub source: Box<dyn FrameSource + Send>,
    pub decoder: Box<dyn QrDecoder + Send>,
    pub uid: String,
    pub mid: String,
    pub stoken: SecretString,
    pub idle_timeout: Duration,
}

/// 跑一次扫码会话，直到它结束，返回结束时的状态快照。
/// `stop` 收到消息时请求停止；登录请求已经发出时，会等登录结果出来再停。
pub async fn run_scan(
    api: &impl LoginApi,
    job: ScanJob,
    ui: &impl ScanUi,
    mut stop: mpsc::Receiver<()>,
) -> ScanStatus {
    let ScanJob {
        source,
        decoder,
        uid,
        mid,
        stoken,
        idle_timeout,
    } = job;
    let credentials = Credentials {
        stoken: &stoken,
        mid: &mid,
    };
    let (mut session, first) = ScanSession::start(
        source.describe(),
        uid,
        idle_timeout,
        Box::new(AlwaysAsk),
        Now::current(),
    );
    ui.show(session.status());

    // 检查凭证、等你回答、登录期间不处理画面（设计文档第 6.2 节第 2 步），截图线程也跟着停下。
    let busy = Arc::new(AtomicBool::new(false));
    let mut frames = spawn_capture(source, decoder, Arc::clone(&busy));
    let mut actions = VecDeque::from([first]);
    loop {
        if !actions.is_empty() {
            busy.store(true, Ordering::Relaxed);
            while let Some(action) = actions.pop_front() {
                let event = match action {
                    Action::CheckCredential => {
                        Event::CredentialChecked(api.check_credential(&credentials).await)
                    }
                    Action::Ask(prompt) => Event::Answered(ui.ask(prompt).await),
                    Action::Login(qr) => Event::LoginFinished(api.login(&qr, &credentials).await),
                    Action::Finish => return session.status().clone(),
                };
                actions.extend(session.handle(event, Now::current()));
                ui.show(session.status());
            }
            busy.store(false, Ordering::Relaxed);
            // 动作之前截到、还留在通道里的画面已经过时，丢掉，只处理之后截到的。
            while frames.try_recv().is_ok() {}
        }
        let event = tokio::select! {
            observed = tokio::time::timeout(TICK, frames.recv()) => match observed {
                Ok(Some(observation)) => Event::Observed(observation),
                Ok(None) => Event::Observed(Observation::CaptureFailed("截图线程意外退出".to_owned())),
                Err(_) => Event::Tick,
            },
            Some(()) = stop.recv() => Event::StopRequested,
        };
        actions.extend(session.handle(event, Now::current()));
        ui.show(session.status());
    }
}

/// 在单独的线程里截图和识别（设计文档第 6.2 节第 2 步）。结果放进容量为 1 的通道，
/// 会话来不及处理时直接丢掉这一帧。`busy` 为真时不截图。会话结束后通道关闭，线程跟着退出。
fn spawn_capture(
    mut source: Box<dyn FrameSource + Send>,
    decoder: Box<dyn QrDecoder + Send>,
    busy: Arc<AtomicBool>,
) -> mpsc::Receiver<Observation> {
    let (sender, receiver) = mpsc::channel(1);
    std::thread::spawn(move || {
        while !sender.is_closed() {
            if busy.load(Ordering::Relaxed) {
                std::thread::sleep(FRAME_INTERVAL);
                continue;
            }
            let started = Instant::now();
            let observation = observe(source.as_mut(), decoder.as_ref());
            let interval = if observation == Observation::TargetMissing {
                SEARCH_INTERVAL
            } else {
                FRAME_INTERVAL
            };
            // 通道满了就丢掉这一帧；通道关了，下一轮循环会退出。
            let _ = sender.try_send(observation);
            if let Some(rest) = interval.checked_sub(started.elapsed()) {
                std::thread::sleep(rest);
            }
        }
    });
    receiver
}
```

```python
"""生成 MhyCarry 的图标：PNG 压缩的 ICO，含 16、32、48、256 四种尺寸。"""
import struct
import sys
import zlib

ACCENT = (0x2D, 0x6A, 0x99, 255)
CLEAR = (0, 0, 0, 0)


def png(size):
    border = max(1, size // 8)
    gap = max(1, size // 8)
    rows = []
    for y in range(size):
        row = bytearray([0])
        for x in range(size):
            edge = min(x, y, size - 1 - x, size - 1 - y)
            row += bytes(CLEAR if border <= edge < border + gap else ACCENT)
        rows.append(bytes(row))

    def chunk(kind, data):
        crc = zlib.crc32(kind + data) & 0xFFFFFFFF
        return struct.pack(">I", len(data)) + kind + data + struct.pack(">I", crc)

    header = struct.pack(">IIBBBBB", size, size, 8, 6, 0, 0, 0)
    return (b"\x89PNG\r\n\x1a\n" + chunk(b"IHDR", header)
            + chunk(b"IDAT", zlib.compress(b"".join(rows), 9)) + chunk(b"IEND", b""))


sizes = [16, 32, 48, 256]
images = [png(size) for size in sizes]
offset = 6 + 16 * len(sizes)
entries = b""
for size, data in zip(sizes, images):
    entries += struct.pack("<BBBBHHII", size % 256, size % 256, 0, 0, 1, 32, len(data), offset)
    offset += len(data)
with open(sys.argv[1], "wb") as out:
    out.write(struct.pack("<HHH", 0, 1, len(sizes)) + entries + b"".join(images))
```

```rust
#[derive(Debug, Clone, PartialEq, Eq, Serialize)]
pub struct AppState {
    pub account: AccountView,

    pub scan: ScanStatus,

#[derive(Debug, Clone, PartialEq, Eq, Serialize)]
#[serde(tag = "kind", rename_all = "snake_case")]
pub enum AccountView {
    /// 未绑定。`notice` 是要显示的原因，比如账号文件损坏、已经改名备份。
    None { notice: Option<String> },
    /// 已绑定。uid 完整显示。
    Bound {
        uid: String,
        bound_at: String,
        credential: Credential,
    },
    /// 账号文件读不了：格式比本程序新（只读），或者读写出错。绑定和解绑都不可用。
    Unavailable { message: String },
}

impl AccountView {
    /// 从读账号文件的结果得出账号状态。
    pub fn from_load(result: Result<AccountFile, StoreError>) -> Self {
        match result {
            Ok(file) => match file.accounts.into_iter().next() {
                Some(account) => AccountView::Bound {
                    uid: account.uid,
                    bound_at: account
                        .bound_at
                        .to_zoned(jiff::tz::TimeZone::system())
                        .strftime("%Y-%m-%d")
                        .to_string(),
                    credential: Credential::Unchecked,
                },
                None => AccountView::None { notice: None },
            },
            Err(error @ StoreError::Corrupt { .. }) => AccountView::None {
                notice: Some(error.to_string()),
            },
            Err(error) => AccountView::Unavailable {
                message: error.to_string(),
            },
        }
    }
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize)]
#[serde(rename_all = "snake_case")]
pub enum Credential {
    Unchecked,
    Valid,
    Invalid,
}

/// 扫描状态变化后，凭证状态跟着变：过了检查凭证这一步就是有效；结束原因是凭证失效就是已失效。
pub fn credential_after(status: &ScanStatus) -> Option<Credential> {
    match status {
        ScanStatus::Idle {
            last: Some(StopReason::CredentialInvalid),
        } => Some(Credential::Invalid),
        ScanStatus::Idle { .. } | ScanStatus::CheckingCredential => None,
        _ => Some(Credential::Valid),
    }
}

/// 绑定流程（设计文档第 6.1、6.3 节）。结束状态一直显示，直到再次绑定或点关闭。
#[derive(Debug, Clone, PartialEq, Eq, Serialize)]
#[serde(tag = "kind", rename_all = "snake_case")]
pub enum BindView {
    Idle,
    Requesting,
    /// `qr` 是绑定二维码的 SVG data URI。
    WaitingScan {
        qr: String,
    },
    WaitingConfirm {
        qr: String,
    },
    Succeeded {
        uid: String,
    },
    Expired,
    Cancelled,
    Failed {
        message: String,
    },
}

impl BindView {
    /// 绑定是否还在进行。
    pub fn in_progress(&self) -> bool {
        matches!(
            self,
            BindView::Requesting | BindView::WaitingScan { .. } | BindView::WaitingConfirm { .. }
        )
    }
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize)]
pub struct SettingsView {
    pub default_target: TargetKind,
    pub idle_timeout_secs: u64,
}

/// 网页端提交的设置，超时不短于 30 秒。
pub fn validated_settings(default_target: TargetKind, idle_timeout_secs: u64) -> ScanSettings {
    ScanSettings {
        default_target,
        idle_timeout_secs: idle_timeout_secs.max(MIN_IDLE_TIMEOUT_SECS),
    }
}

/// 把绑定二维码画成 SVG，编码成 data URI 给界面的 `<img>` 用（CSP 只放行 data: 图片）。
pub fn qr_data_uri(content: &str) -> Result<String, qrcode::types::QrError> {
    let svg = QrCode::new(content.as_bytes())?
        .render::<svg::Color<'_>>()
        .min_dimensions(200, 200)
        .dark_color(svg::Color("#000000"))
        .light_color(svg::Color("#ffffff"))
        .build();
    Ok(format!(
        "data:image/svg+xml;base64,{}",
        BASE64_STANDARD.encode(svg)
    ))
}
```

```rust
/// 交给 Tauri 管理的共享状态。

    model: Mutex<Model>,
    pub store: JsonFileStore,
    pub settings_path: PathBuf,
    pub api: ApiClient,
}

impl Shared {
    /// 启动时读取设置和账号文件。打开程序时不联网（设计文档第 6.3 节）。
    pub fn load() -> Result<Self, Box<dyn Error>> {
        let settings_path = paths::settings_path()?;
        let settings = Settings::load_or_init(&settings_path)?;
        let store = JsonFileStore::new(paths::accounts_path()?);
        let api = ApiClient::new(settings.device_id.clone())?;
        let mut model = Model {
            account: AccountView::None { notice: None },
            bind: BindView::Idle,
            scan: ScanStatus::Idle { last: None },
            settings,
            leftovers: 0,
            bind_task: None,
            scan_stop: None,
            last_sent: None,
        };
        reload_account(&mut model, &store);
        Ok(Self {
            model: Mutex::new(model),
            store,
            settings_path,
            api,
        })
    }

    pub fn lock(&self) -> MutexGuard<'_, Model> {
        // 锁只在同步代码里短暂持有；万一中毒了，照常用里面的数据。
        self.model
            .lock()
            .unwrap_or_else(|poisoned| poisoned.into_inner())
    }

    pub fn snapshot(&self) -> AppState {
        snapshot_of(&self.lock(), &self.store)
    }
}

fn snapshot_of(model: &Model, store: &JsonFileStore) -> AppState {
    AppState {
        account: model.account.clone(),
        bind: model.bind.clone(),
        scan: model.scan.clone(),
        scan_text: model.scan.to_string(),
        notice_text: model.scan.notice().map(ToString::to_string),
        settings: SettingsView {
            default_target: model.settings.scan.default_target,
            idle_timeout_secs: model.settings.scan.idle_timeout_secs,
        },
        credential_file: store.path().display().to_string(),
        leftovers: model.leftovers,
    }
}

/// 修改状态，有变化就把新的完整快照推送给界面。
pub fn update(app: &AppHandle, change: impl FnOnce(&mut Model)) {
    let shared = app.state::<Shared>();
    let snapshot = {
        let mut model = shared.lock();
        change(&mut model);
        let snapshot = snapshot_of(&model, &shared.store);
        if model.last_sent.as_ref() == Some(&snapshot) {
            return;
        }
        model.last_sent = Some(snapshot.clone());
        snapshot
    };
    let _ = app.emit(STATE_EVENT, snapshot);
}

/// 重新读账号文件，刷新账号状态和残留文件数。
pub fn reload_account(model: &mut Model, store: &JsonFileStore) {
    model.account = AccountView::from_load(store.load());
    model.leftovers = store.leftover_files().map_or(0, |files| files.len());
}
```

```rust
//! 绑定账号：用米游社 App 扫码（设计文档第 6.1 节）。

use std::time::Duration;

use mhy_carry_api::{ApiError, BindStatus, retcode};
use mhy_carry_core::account::{Account, AccountFile};
use mhy_carry_core::store::{AccountStore, StoreError};
use tauri::{AppHandle, Manager};

use crate::model::{Shared, reload_account, update};
use crate::state::{BindView, qr_data_uri};

const POLL_INTERVAL: Duration = Duration::from_secs(2);
/// 查询状态没有副作用，网络出错允许重试一次，连续两次就放弃（设计文档第 10 节）。
const MAX_NETWORK_ERRORS_IN_A_ROW: u32 = 2;

/// 跑完一次绑定，把结果写进状态。
pub async fn run(app: AppHandle) {
    let outcome = bind(&app).await;
    let shared = app.state::<Shared>();
    update(&app, |model| {
        if matches!(outcome, BindView::Succeeded { .. }) {
            reload_account(model, &shared.store);
        }
        model.bind = outcome;
    });
}

async fn bind(app: &AppHandle) -> BindView {
    let shared = app.state::<Shared>();
    let qr = match shared.api.create_bind_qr().await {
        Ok(qr) => qr,
        Err(error) => {
            return BindView::Failed {
                message: error.to_string(),
            };
        }
    };
    let image = match qr_data_uri(&qr.url) {
        Ok(image) => image,
        Err(error) => {
            return BindView::Failed {
                message: format!("生成二维码失败：{error}"),
            };
        }
    };
    update(app, |model| {
        model.bind = BindView::WaitingScan { qr: image.clone() }
    });

    let mut network_errors = 0;
    loop {
        tokio::time::sleep(POLL_INTERVAL).await;
        match shared.api.query_bind_qr(&qr.ticket).await {
            Ok(BindStatus::Created) => network_errors = 0,
            Ok(BindStatus::Scanned) => {
                network_errors = 0;
                update(app, |model| {
                    model.bind = BindView::WaitingConfirm { qr: image.clone() }
                });
            }
            Ok(BindStatus::Confirmed(bound)) => {
                let uid = bound.uid.clone();
                let account =
                    Account::new(bound.uid, bound.mid, bound.stoken, jiff::Timestamp::now());
                return match save(&shared, account) {
                    Ok(()) => BindView::Succeeded { uid },
                    Err(message) => BindView::Failed { message },
                };
            }
            Err(ApiError::Network(_)) if network_errors + 1 < MAX_NETWORK_ERRORS_IN_A_ROW => {
                network_errors += 1;
            }
            Err(error) if error.retcode() == Some(retcode::QR_EXPIRED) => return BindView::Expired,
            Err(error) if error.retcode() == Some(retcode::QR_CANCELLED) => {
                return BindView::Cancelled;
            }
            Err(error) => {
                return BindView::Failed {
                    message: error.to_string(),
                };
            }
        }
    }
}

/// 保存账号。v1 只支持一个账号，新账号替换旧的（设计文档第 6.1 节）。
fn save(shared: &Shared, account: Account) -> Result<(), String> {
    let mut file = match shared.store.load() {
        Ok(file) => file,
        // 损坏的文件已经改名备份了，从空文件开始。
        Err(StoreError::Corrupt { .. }) => AccountFile::empty(),
        Err(error) => return Err(error.to_string()),
    };
    file.accounts = vec![account];
    shared.store.save(&file).map_err(|error| error.to_string())
}
```

```rust
#[tauri::command(rename_all = "snake_case")]
pub async fn scan_start(app: AppHandle, target: TargetKind, id: Option<u32>) -> CommandResult {
    let (stop, stop_signal) = mpsc::channel(1);
    let idle_timeout = {
        let shared = app.state::<Shared>();
        let mut model = shared.lock();
        if model.scanning() {
            return Ok(());
        }
        if model.bind.in_progress() {
            return Err("绑定中不能开始扫描。".to_owned());

        model.settings.scan.idle_timeout()

        Ok(job) => {
            scan::spawn(app, job, stop_signal);

        }
        Err(message) => {

            Err(message)
        }
    }

fn prepare_job(
    app: &AppHandle,
    target: TargetKind,
    id: Option<u32>,
    idle_timeout: Duration,
) -> CommandResult<ScanJob> {
    let shared = app.state::<Shared>();
    let account = shared
        .store
        .load()
        .map_err(|error| error.to_string())?
        .accounts
        .into_iter()
        .next()
        .ok_or("还没有绑定账号，先用米游社扫码绑定。")?;
    let source: Box<dyn FrameSource + Send> = match target {
        TargetKind::Auto => Box::new(GameWindowSource::new(GAMES)),
        TargetKind::Window => {
            let id = id.ok_or("先选择要扫描的窗口。")?;
            let window = list_windows()
                .map_err(|error| error.to_string())?
                .into_iter()
                .find(|window| window.id == id)
                .ok_or("这个窗口已经不在了，请刷新列表。")?;
            Box::new(PickedWindowSource::new(&window))
        }
        TargetKind::Monitor => {
            let id = id.ok_or("先选择要扫描的显示器。")?;
            let monitor = list_monitors()
                .map_err(|error| error.to_string())?
                .into_iter()
                .find(|monitor| monitor.id == id)
                .ok_or("这个显示器已经不在了，请刷新列表。")?;
            Box::new(MonitorSource::new(&monitor))
        }
    };
    Ok(ScanJob {
        source,
        decoder: Box::new(RxingDecoder),
        uid: account.uid,
        mid: account.mid,
        stoken: account.stoken,
        idle_timeout,
    })
}

#[tauri::command]
pub fn scan_stop(shared: State<'_, Shared>) {
    if let Some(stop) = &shared.lock().scan_stop {
        let _ = stop.try_send(());
    }
}

#[tauri::command(rename_all = "snake_case")]
pub fn update_settings(
    app: AppHandle,
    default_target: TargetKind,
    idle_timeout_secs: u64,
) -> CommandResult {
    let shared = app.state::<Shared>();
    let mut result = Ok(());
    update(&app, |model| {
        model.settings.scan = validated_settings(default_target, idle_timeout_secs);
        result = model
            .settings
            .save(&shared.settings_path)
            .map_err(|error| error.to_string());
    });
    result
}
```

```js
function el(tag, attrs = {}, text) {
  const node = document.createElement(tag);
  for (const [key, value] of Object.entries(attrs)) node.setAttribute(key, value);
  if (text !== undefined) node.textContent = text;

}

function button(label, className, onClick) {

function showError(error) {
  $("error").textContent = String(error);

async function call(command, args) {
  $("error").hidden = true;
  try {
    return await invoke(command, args);
  } catch (error) {
    showError(error);
    return null;
  }
}

function currentTarget() {
  return target ?? state.settings.default_target;
}

  const { account, bind } = state;
  if (bind.kind !== "idle" && bind.kind !== "succeeded") {

function dotClass(scan) {
  if (scan.kind === "scanning" || scan.kind === "logging_in") return "scanning";
  if (WAITING.includes(scan.kind)) return "waiting";
  if (scan.kind === "idle" && scan.last) {
    if (scan.last.kind === "logged_in") return "ok";
    if (BAD_STOPS.includes(scan.last.kind)) return "bad";
  }
  return "";

async function loadTargets(kind) {
  targetList = [];
  fillTargets();
  if (kind === "auto") return;
  targetList = (await call("list_targets", { kind })) ?? [];
  fillTargets();

function fillTargets() {
  const select = $("target-select");
  const keep = select.value;
  select.replaceChildren(...targetList.map((item) =>
    el("option", { value: String(item.id) }, item.label + (item.is_primary ? "（主显示器）" : ""))));
  const primary = targetList.find((item) => item.is_primary);
  if (targetList.some((item) => String(item.id) === keep)) select.value = keep;
  else if (primary) select.value = String(primary.id);
}

function renderScan() {
  const scan = state.scan;
  const idle = scan.kind === "idle";
  const chosen = currentTarget();
  for (const name of TARGETS) {
    const node = $("target-" + name);
    node.setAttribute("aria-pressed", String(name === chosen));
    node.disabled = !idle;
  }
  $("target-pick").hidden = chosen === "auto";
  $("target-select").disabled = !idle;
  $("target-refresh").disabled = !idle;

  const start = $("scan-button");
  if (idle) {
    const ready = state.account.kind === "bound" && state.account.credential !== "invalid"
      && !BUSY_BIND.includes(state.bind.kind);
    start.textContent = "开始扫描";
    start.disabled = !ready;
  } else {
    start.textContent = "停止";
    // 登录请求已经发出，要等结果出来。
    start.disabled = scan.kind === "logging_in";
  }

  $("status-dot").className = "dot " + dotClass(scan);
  $("status-text").textContent = state.scan_text;
  const notice = $("status-notice");
  notice.replaceChildren();
  if (state.notice_text !== lastNotice) {
    lastNotice = state.notice_text;
    noticeTime = new Date().toLocaleTimeString("zh-CN", { hour12: false });
  }
  if (state.notice_text) {
    notice.append(el("time", {}, noticeTime), "提示：" + state.notice_text);
  } else if (idle && state.account.kind !== "bound") {
    notice.textContent = "绑定账号后才能开始扫描。";
  }
}

function renderSettings() {
  const select = $("setting-target");
  const input = $("setting-timeout");
  if (document.activeElement !== select) select.value = state.settings.default_target;
  if (document.activeElement !== input) input.value = String(state.settings.idle_timeout_secs);
}

function saveSettings() {
  call("update_settings", {
    default_target: $("setting-target").value,
    idle_timeout_secs: Math.max(30, Number($("setting-timeout").value) || 300),
  });
}

function renderFooter() {
  const footer = $("footer");
  footer.replaceChildren("凭证明文保存在 ", el("code", {}, state.credential_file), "，解绑会删除它。");
  if (state.leftovers > 0) {
    footer.append(el("div", {}, "另有 " + state.leftovers + " 个旧账号文件（账号文件损坏时留下的备份），解绑时一并删除。"));
  }
}

function render(next) {
  state = next;
  renderAccount();
  renderScan();
  renderSettings();
  renderFooter();
}

for (const name of TARGETS) {
  $("target-" + name).addEventListener("click", () => {
    target = name;
    renderScan();
    loadTargets(name);
  });
}
$("target-refresh").addEventListener("click", () => loadTargets(currentTarget()));
$("scan-button").addEventListener("click", () => {
  if (state.scan.kind !== "idle") {
    call("scan_stop");
    return;
  }
  const chosen = currentTarget();
  const id = chosen === "auto" ? null : Number($("target-select").value) || null;
  call("scan_start", { target: chosen, id });
});
$("setting-target").addEventListener("change", saveSettings);
$("setting-timeout").addEventListener("change", saveSettings);

async function main() {
  render(await invoke("get_state"));
  await listen("state-changed", (event) => render(event.payload));
  loadTargets(currentTarget());
}

main().catch(showError);
```
