# MhyCarry M0 + M1 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 搭好仓库骨架和 CI（M0），并做出一个能用命令行绑定账号、把原神客户端登录成功的 `mhy-carry-cli`，同时完成截图方案实验（M1）。

**架构：** Cargo workspace，含 `core`（纯逻辑：二维码校验、游戏配置、账号和设置文件）、`api`（米哈游接口客户端，带域名白名单）、`platform`（数据目录）、`cli`（命令行）四个 crate。截图实验放在 workspace 之外的 `spikes/capture-bench`，不进正式代码。Tauri 应用、自动扫描、二维码识别留到 M2、M3 的计划。

**技术栈：** Rust 1.99.0（edition 2024）、reqwest 0.13（默认 rustls + 系统证书库）、tokio、serde、url、secrecy、jiff、uuid、thiserror、clap、qrcode、rxing、proptest、wiremock、tempfile、dirs、xcap（仅实验）。

**接口：** 扫码登录走“panda 扫码 → passport 扫码 → 确认”三步，绑定账号走 HoYoPlay 的 passport 扫码登录。细节见设计文档第 6 节，来源见第 16 节。

**设计文档：** [docs/design/2026-10-11-mhy-carry-design.md](../design/2026-10-11-mhy-carry-design.md)

**状态（2026-10-12）：** M0、M1 已完成。实际执行和本计划的差异：提交时都带上了 `Cargo.lock`；任务 18 的 rxing 只开二维码识别功能，截图由 image 解码成灰度后再交给它（默认功能会带进无人维护的依赖，过不了 cargo-deny）；推送前按独立审查意见修了 5 处（多个登录码时拒绝、非 UTF-8 文件按损坏处理、先查 retcode、格式错误不回显字段原值、转义二维码参数）。实测结论见设计文档第 14 节。

```rust
//! 支持的游戏。加一个游戏就是在 `GAMES` 里加一条记录。

/// 一个游戏（一个服务器）的静态配置。
#[derive(Debug, PartialEq, Eq)]
pub struct GameProfile {
    /// 界面上显示的游戏名。确认弹窗里的游戏名只用这里的，不用二维码里的 `app_name`。
    pub display_name: &'static str,
    /// 二维码和扫码接口里的 `app_id`。
    pub app_id: u32,
    /// 二维码里的 `biz_key`，同时也是 panda 扫码接口路径里的那一段，比如 `hk4e_cn`。
    pub biz_key: &'static str,
    /// passport 扫码（scanQRLogin）返回的应用 ID。确认登录前要核对它，
    /// 防止把账号登录到别的应用上。
    pub passport_app_id: &'static str,
    /// 用来自动找游戏窗口的进程名。
    pub process_names: &'static [&'static str],
}

pub static GAMES: &[GameProfile] = &[GameProfile {
    display_name: "原神",
    app_id: 4,
    biz_key: "hk4e_cn",
    // 来自其他开源项目的抓包记录，M1 用真实账号确认（设计文档第 14 节）。
    passport_app_id: "c76ync6mutq8",
```

```rust
//! 校验游戏客户端显示的登录二维码。所有条件都满足才算合法，否则忽略这个二维码。

use url::Url;

use crate::games::{self, GameProfile};

const HOST: &str = "user.mihoyo.com";
const PATH: &str = "/qr_code_in_game.html";
/// 允许本机时钟比服务器慢的秒数。
const CLOCK_SKEW_SECS: i64 = 60;

/// 校验通过的游戏登录二维码。
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct LoginQr {
    pub game: &'static GameProfile,
    pub ticket: String,
    /// 过期时间，Unix 秒。
    pub expire: i64,
}

#[derive(Debug, Clone, PartialEq, Eq, thiserror::Error)]
pub enum QrError {
    #[error("不是网址")]
    NotUrl,
    #[error("不是 https 链接")]
    NotHttps,
    #[error("域名不是 user.mihoyo.com")]
    WrongHost,
    #[error("路径不对")]
    WrongPath,
    #[error("缺少参数 {0}")]
    MissingParam(&'static str),
    #[error("参数 {0} 出现了不止一次")]
    DuplicateParam(&'static str),
    #[error("参数 {0} 格式不对")]
    BadParam(&'static str),
    #[error("不支持的游戏（app_id={app_id}，biz_key={biz_key}）")]
    UnknownGame { app_id: String, biz_key: String },
    #[error("二维码已过期")]
    Expired,
}

/// 校验二维码文本。`now_unix` 是当前时间（Unix 秒）。
pub fn parse_login_qr(text: &str, now_unix: i64) -> Result<LoginQr, QrError> {
    let url = Url::parse(text.trim()).map_err(|_| QrError::NotUrl)?;
    if url.scheme() != "https" {
        return Err(QrError::NotHttps);
    }
    let has_userinfo = !url.username().is_empty() || url.password().is_some();
    if has_userinfo || url.port().is_some() || url.host_str() != Some(HOST) {
        return Err(QrError::WrongHost);
    }
    if url.path() != PATH {
        return Err(QrError::WrongPath);
    }

    let app_id = single_param(&url, "app_id")?;
    let biz_key = single_param(&url, "biz_key")?;
    let ticket = single_param(&url, "ticket")?;
    let expire = single_param(&url, "expire")?;

    let app_id_num: u32 = app_id.parse().map_err(|_| QrError::BadParam("app_id"))?;
    let game =
        games::find(app_id_num, &biz_key).ok_or(QrError::UnknownGame { app_id, biz_key })?;

    let ticket_ok =
        (16..=64).contains(&ticket.len()) && ticket.bytes().all(|b| b.is_ascii_alphanumeric());
    if !ticket_ok {
        return Err(QrError::BadParam("ticket"));
    }

    let expire: i64 = expire.parse().map_err(|_| QrError::BadParam("expire"))?;
    if expire <= now_unix - CLOCK_SKEW_SECS {
        return Err(QrError::Expired);
    }

    Ok(LoginQr {
        game,
        ticket,
        expire,
    })
}

/// 取一个只能出现一次的参数。
fn single_param(url: &Url, name: &'static str) -> Result<String, QrError> {
    let mut values = url
        .query_pairs()
        .filter(|(key, _)| key == name)
        .map(|(_, value)| value.into_owned());
    let first = values.next().ok_or(QrError::MissingParam(name))?;
    if values.next().is_some() {
        return Err(QrError::DuplicateParam(name));
    }
    Ok(first)
}
```

```rust
//! 文件读写的小工具。

use std::ffi::OsString;
use std::fs::{self, File};
use std::io::{self, Write};
use std::path::{Path, PathBuf};

/// 原子写入：先在同目录写临时文件并刷到磁盘，再替换目标文件。
/// 写到一半断电时，目标文件要么是旧内容，要么是新内容，不会只剩半截。
pub fn atomic_write(path: &Path, contents: &[u8]) -> io::Result<()> {
    let file_name = path
        .file_name()
        .ok_or_else(|| io::Error::new(io::ErrorKind::InvalidInput, "路径里没有文件名"))?;
    let dir = match path.parent() {
        Some(parent) if !parent.as_os_str().is_empty() => parent,
        _ => Path::new("."),
    };
    fs::create_dir_all(dir)?;

    let mut tmp_name = file_name.to_os_string();
    tmp_name.push(".tmp");
    let tmp = dir.join(tmp_name);
    {
        let mut file = File::create(&tmp)?;
        file.write_all(contents)?;
        file.sync_all()?;
    }
    // Windows 上 std::fs::rename 会直接替换已存在的目标文件。
    fs::rename(&tmp, path)
}

/// 损坏文件的备份路径：同目录下的 `<原文件名>.bak-<Unix 秒>`。
pub fn backup_path(path: &Path) -> PathBuf {
    let mut name: OsString = path.file_name().unwrap_or_default().to_os_string();
    name.push(format!(".bak-{}", jiff::Timestamp::now().as_second()));
    path.with_file_name(name)
}
```

```rust
/// 只保留第一位和最后三位，中间固定显示 4 个星号，不暴露 uid 的长度。
pub fn mask_uid(uid: &str) -> String {
    let chars: Vec<char> = uid.chars().collect();
    if chars.len() <= 4 {
        return "****".to_owned();
    }
    let first = chars[0];
    let last3: String = chars[chars.len() - 3..].iter().collect();
```

```rust
//! 账号文件的读写。v1 只有明文 JSON 一种实现，以后加密时再加一种实现。

use std::fs;
use std::io;
use std::path::{Path, PathBuf};

use serde::Deserialize;

use crate::account::{ACCOUNT_FILE_FORMAT, AccountFile, ENCRYPTION_NONE};
use crate::fsutil::{atomic_write, backup_path};

#[derive(Debug, thiserror::Error)]
pub enum StoreError {
    #[error("读写账号文件失败（{path}）：{source}")]
    Io {
        path: PathBuf,
        #[source]
        source: io::Error,
    },
    #[error("账号文件已损坏，已改名为 {backup}，请重新绑定账号")]
    Corrupt { backup: PathBuf },
    #[error(
        "账号文件来自更新版本的 MhyCarry（format={format}，encryption={encryption}），为免损坏，本程序不会修改它"
    )]
    UnsupportedFormat { format: u32, encryption: String },
    #[error("生成账号文件内容失败：{0}")]
    Serialize(#[from] serde_json::Error),
}

pub trait AccountStore {
    fn load(&self) -> Result<AccountFile, StoreError>;
    fn save(&self, file: &AccountFile) -> Result<(), StoreError>;
}

/// 明文 JSON 文件。
pub struct JsonFileStore {
    path: PathBuf,
}

/// 只读文件头，判断格式版本和加密方式。
#[derive(Deserialize)]
struct Header {
    format: u32,
    encryption: String,
}

enum OnDisk {
    Missing,
    Supported(String),
    Unsupported { format: u32, encryption: String },
    Unparsable,
}

impl JsonFileStore {
    pub fn new(path: impl Into<PathBuf>) -> Self {
        Self { path: path.into() }
    }

    pub fn path(&self) -> &Path {
        &self.path
    }

    fn io_error(&self, source: io::Error) -> StoreError {
        StoreError::Io {
            path: self.path.clone(),
            source,
        }
    }

    fn read_on_disk(&self) -> Result<OnDisk, StoreError> {
        let text = match fs::read_to_string(&self.path) {
            Ok(text) => text,
            Err(e) if e.kind() == io::ErrorKind::NotFound => return Ok(OnDisk::Missing),
            Err(e) => return Err(self.io_error(e)),
        };
        Ok(match serde_json::from_str::<Header>(&text) {
            Err(_) => OnDisk::Unparsable,
            Ok(h) if h.format > ACCOUNT_FILE_FORMAT || h.encryption != ENCRYPTION_NONE => {
                OnDisk::Unsupported {
                    format: h.format,
                    encryption: h.encryption,
                }
            }
            Ok(_) => OnDisk::Supported(text),
        })
    }

    fn back_up_corrupt_file(&self) -> Result<PathBuf, StoreError> {
        let backup = backup_path(&self.path);
        fs::rename(&self.path, &backup).map_err(|e| self.io_error(e))?;
        Ok(backup)
    }
}

impl AccountStore for JsonFileStore {
    fn load(&self) -> Result<AccountFile, StoreError> {
        match self.read_on_disk()? {
            OnDisk::Missing => Ok(AccountFile::empty()),
            OnDisk::Unsupported { format, encryption } => {
                Err(StoreError::UnsupportedFormat { format, encryption })
            }
            OnDisk::Unparsable => Err(StoreError::Corrupt {
                backup: self.back_up_corrupt_file()?,
            }),
            OnDisk::Supported(text) => match serde_json::from_str(&text) {
                Ok(file) => Ok(file),
                Err(_) => Err(StoreError::Corrupt {
                    backup: self.back_up_corrupt_file()?,
                }),
            },
        }
    }

    fn save(&self, file: &AccountFile) -> Result<(), StoreError> {
        match self.read_on_disk()? {
            OnDisk::Unsupported { format, encryption } => {
                return Err(StoreError::UnsupportedFormat { format, encryption });
            }
            OnDisk::Unparsable => {
                self.back_up_corrupt_file()?;
            }
            OnDisk::Missing | OnDisk::Supported(_) => {}
        }
        let json = serde_json::to_string_pretty(file)?;
        atomic_write(&self.path, json.as_bytes()).map_err(|e| self.io_error(e))
    }
}
```

```rust
use std::io;
use std::path::{Path, PathBuf};

use serde::{Deserialize, Serialize};

pub const SETTINGS_FORMAT: u32 = 1;

#[derive(Debug, Serialize, Deserialize, PartialEq, Eq)]
pub struct Settings {
    pub format: u32,
    /// 首次运行时随机生成的 UUID v4，之后固定不变。
    pub device_id: String,
}

#[derive(Debug, thiserror::Error)]
pub enum SettingsError {
    #[error("读写设置文件失败（{path}）：{source}")]
    Io {
        path: PathBuf,
        #[source]
        source: io::Error,
    },

impl Settings {
    /// 读取设置。文件不存在就生成新的设备 ID 并保存；
    /// 文件损坏就改名备份后重新生成（设置里没有凭证，最坏只是设备 ID 变了）。
    pub fn load_or_init(path: &Path) -> Result<Self, SettingsError> {

            device_id: uuid::Uuid::new_v4().to_string(),
        };
        settings.save(path)?;
        Ok(settings)
    }

        let json = serde_json::to_string_pretty(self)?;
        atomic_write(path, json.as_bytes()).map_err(|source| SettingsError::Io {
            path: path.to_path_buf(),
```

```rust
use std::ffi::OsString;

/// 设置后用它作为数据目录，开发调试时用来避开真实账号。
pub const DATA_DIR_ENV: &str = "MHY_CARRY_DATA_DIR";
const APP_DIR_NAME: &str = "MhyCarry";

#[derive(Debug, thiserror::Error)]
#[error("找不到系统的本地应用数据目录（%LOCALAPPDATA%）")]
pub struct NoDataDir;

    Ok(data_dir()?.join("settings.json"))

        return Ok(PathBuf::from(dir));
```

```rust
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct PassportTicket {
    pub tk: String,
    pub token_types: Vec<String>,
}

/// 校验 panda 扫码返回的 `passport_qr_url`，取出 `tk` 和 `token_types`。
pub fn parse_passport_url(text: &str) -> Result<PassportTicket, QrError> {
    let url = parse_mihoyo_url(text)?;
    if url.path() != PASSPORT_PATH {
        return Err(QrError::WrongPath);
    }
    let tk = single_param(&url, "tk")?;
    let types = single_param(&url, "token_types")?;

    let tk_ok = (8..=64).contains(&tk.len())
        && tk.bytes().all(|b| b.is_ascii_alphanumeric() || b == b'-');
    if !tk_ok {
        return Err(QrError::BadParam("tk"));
    }

    let token_types: Vec<String> = types.split(',').map(str::to_owned).collect();
    let types_ok = token_types
        .iter()
        .all(|t| !t.is_empty() && t.bytes().all(|b| b.is_ascii_digit()));
    if !types_ok {
        return Err(QrError::BadParam("token_types"));
    }

    Ok(PassportTicket { tk, token_types })
}
```

```rust
pub mod retcode {
    /// 登录状态失效（stoken 过期或被下线）。
    pub const TOKEN_INVALID: i64 = -100;
    /// 二维码已过期。

    pub const QR_CANCELLED: i64 = -3505;

#[derive(Debug, thiserror::Error)]
pub enum ApiError {
    #[error("网络请求失败：{0}")]
    Network(reqwest::Error),
    #[error("服务器返回 HTTP {0}")]
    Status(u16),
    #[error("{}", describe_retcode(.code, .message))]
    Retcode { code: i64, message: String },
    #[error("返回内容格式不对，接口可能已变更：{0}")]
    Format(String),
    #[error("请求被拦截：{0}")]
    Blocked(String),
}

impl ApiError {
    /// reqwest 的错误信息会带上完整 URL，统一先去掉。

        Self::Network(error.without_url())
    }

    pub fn retcode(&self) -> Option<i64> {
        match self {
            Self::Retcode { code, .. } => Some(*code),
            _ => None,
        }
    }
}
```

```rust
//! 域名白名单。每个请求发出前都要过这一关。

use url::Url;

use crate::endpoints::{PANDA_HOST, PASSPORT_HOST};
use crate::error::ApiError;

#[derive(Debug, Clone)]
pub struct HostPolicy {
    hosts: Vec<String>,
    require_https: bool,
}

impl HostPolicy {
    pub fn official() -> Self {
        Self {
            hosts: vec![PANDA_HOST.to_owned(), PASSPORT_HOST.to_owned()],
            require_https: true,
        }
    }

    /// 只允许本地假服务器，用于测试。
    #[cfg(test)]
    pub fn local_for_tests() -> Self {
        Self {
            hosts: vec!["127.0.0.1".to_owned()],
            require_https: false,
        }
    }

    pub fn require_https(&self) -> bool {
        self.require_https
    }

    pub fn check(&self, url: &Url) -> Result<(), ApiError> {
        if self.require_https && url.scheme() != "https" {
            return Err(ApiError::Blocked(format!("只允许 https，实际是 {}", url.scheme())));
        }
        if !url.username().is_empty() || url.password().is_some() {
            return Err(ApiError::Blocked("地址里不能带用户名或密码".to_owned()));
        }
        let host = url.host_str().unwrap_or_default();
        if !self.hosts.iter().any(|allowed| allowed == host) {
            return Err(ApiError::Blocked(format!("域名不在白名单里：{host}")));
        }
        Ok(())
    }
}
```

```rust
//! 米哈游接口统一的返回结构 `{retcode, message, data}`。

use serde::Deserialize;

use crate::error::ApiError;

#[derive(Debug, Deserialize)]
pub struct Envelope<T> {
    retcode: i64,
    #[serde(default)]
    message: String,
    data: Option<T>,
}

impl<T> Envelope<T> {
    /// retcode 为 0 时取出 data；data 缺失也算错误。
    pub fn into_data(self) -> Result<T, ApiError> {
        self.check()?;
        self.data
            .ok_or_else(|| ApiError::Format("返回内容里没有 data".to_owned()))
    }

    /// 只要求 retcode 为 0，不关心 data。
    pub fn ensure_ok(self) -> Result<(), ApiError> {
        self.check()
    }

    fn check(&self) -> Result<(), ApiError> {
        if self.retcode == 0 {
            Ok(())
        } else {
            Err(ApiError::Retcode {
                code: self.retcode,
                message: self.message.clone(),
            })
        }
    }
}

#[cfg(test)]
mod tests {
    use super::*;
    use serde::de::IgnoredAny;

        serde_json::from_str(json).unwrap()
```

```rust
//! ApiClient：所有请求都从这里发出。

use std::time::Duration;

use reqwest::header::{CONTENT_TYPE, HeaderMap, HeaderValue};
use serde::Serialize;
use serde::de::DeserializeOwned;
use url::Url;

use crate::endpoints::Endpoints;
use crate::envelope::Envelope;
use crate::error::ApiError;
use crate::guard::HostPolicy;

const TIMEOUT: Duration = Duration::from_secs(10);

pub struct ApiClient {
    pub(crate) http: reqwest::Client,
    pub(crate) policy: HostPolicy,
    pub(crate) endpoints: Endpoints,
    pub(crate) device_id: String,
}

impl ApiClient {
    /// 正式客户端：只能访问官方域名，只用 https，不跟随重定向。
    pub fn new(device_id: impl Into<String>) -> Result<Self, ApiError> {
        Self::build(device_id.into(), Endpoints::official(), HostPolicy::official())
    }

    /// 测试客户端：所有接口指向本地假服务器。
    #[cfg(test)]
    pub(crate) fn for_tests(base: &str) -> Self {
        Self::build(
            "test-device".to_owned(),
            Endpoints::all_at(base),
            HostPolicy::local_for_tests(),
        )
        .expect("构建测试客户端")
    }

    fn build(device_id: String, endpoints: Endpoints, policy: HostPolicy) -> Result<Self, ApiError> {
        let http = reqwest::Client::builder()
            .redirect(reqwest::redirect::Policy::none())
            .timeout(TIMEOUT)
            .https_only(policy.require_https())
            .build()
            .map_err(ApiError::network)?;
        Ok(Self {
            http,
            policy,
            endpoints,
            device_id,
        })
    }

    pub(crate) fn device_header(&self) -> Result<HeaderValue, ApiError> {
        HeaderValue::from_str(&self.device_id)
            .map_err(|_| ApiError::Format("设备 ID 里有非法字符".to_owned()))
    }

    pub(crate) async fn post_json<B: Serialize, T: DeserializeOwned>(
        &self,
        url: Url,
        headers: HeaderMap,
        body: &B,
    ) -> Result<Envelope<T>, ApiError> {
        let body = serde_json::to_string(body).map_err(|e| ApiError::Format(e.to_string()))?;
        self.post_text(url, headers, body).await
    }

    /// 发送已经序列化好的 JSON 请求体。需要对请求体签名时（任务 19）用得上。
    pub(crate) async fn post_text<T: DeserializeOwned>(
        &self,
        url: Url,
        headers: HeaderMap,
        body: String,
    ) -> Result<Envelope<T>, ApiError> {
        self.policy.check(&url)?;
        let response = self
            .http
            .post(url)
            .headers(headers)
            .header(CONTENT_TYPE, "application/json")
            .body(body)
            .send()
            .await
            .map_err(ApiError::network)?;
        read_envelope(response).await
    }

    pub(crate) async fn get_json<T: DeserializeOwned>(
        &self,
        url: Url,
        headers: HeaderMap,
    ) -> Result<Envelope<T>, ApiError> {
        self.policy.check(&url)?;
        let response = self
            .http
            .get(url)
            .headers(headers)
            .send()
            .await
            .map_err(ApiError::network)?;
        read_envelope(response).await
    }
}

async fn read_envelope<T: DeserializeOwned>(
    response: reqwest::Response,
) -> Result<Envelope<T>, ApiError> {
    let status = response.status();
    if !status.is_success() {
        return Err(ApiError::Status(status.as_u16()));
    }
    let bytes = response.bytes().await.map_err(ApiError::network)?;
    serde_json::from_slice(&bytes).map_err(|e| ApiError::Format(e.to_string()))
}
```

```rust
use mhy_carry_core::account::{ExposeSecret, SecretString};
use mhy_carry_core::qr::{LoginQr, PassportTicket, parse_passport_url};
use reqwest::header::{COOKIE, HeaderMap, HeaderValue};

use serde::de::IgnoredAny;
use serde_json::json;

use crate::client::ApiClient;
use crate::error::ApiError;

/// 米游社 App 的应用 ID。
const BBS_APP_ID: &str = "bll8iq97cem8";
const CHECK_STOKEN_PATH: &str = "/account/auth/api/getCookieAccountInfoBySToken";
const SCAN_PATH: &str = "/account/ma-cn-passport/app/scanQRLogin";
const CONFIRM_PATH: &str = "/account/ma-cn-passport/app/confirmQRLogin";

/// 账号凭证：v2 stoken 和 mid。
pub struct Credentials<'a> {
    pub stoken: &'a SecretString,
    pub mid: &'a str,
}

/// passport 扫码后，服务器认定的登录目标应用。
#[derive(Debug, Clone, Deserialize)]
pub struct ScannedApp {
    #[serde(default)]
    pub app_id: String,
    #[serde(default)]
    pub app_name: String,
}

#[derive(Deserialize)]
struct PandaScanData {
    passport_qr_url: String,
}

impl ApiClient {
    fn bbs_headers(&self, credentials: Option<&Credentials<'_>>) -> Result<HeaderMap, ApiError> {
        let mut headers = HeaderMap::new();
        headers.insert("x-rpc-app_id", HeaderValue::from_static(BBS_APP_ID));
        headers.insert("x-rpc-device_id", self.device_header()?);
        if let Some(credentials) = credentials {
            let cookie = format!(
                "stoken={};mid={}",
                credentials.stoken.expose_secret(),
                credentials.mid
            );
            let mut cookie = HeaderValue::from_str(&cookie)
                .map_err(|_| ApiError::Format("账号凭证里有非法字符".to_owned()))?;
            cookie.set_sensitive(true);
            headers.insert(COOKIE, cookie);
        }
        Ok(headers)
    }

    /// 检查 stoken 是否仍然有效。
    pub async fn check_stoken(&self, credentials: &Credentials<'_>) -> Result<(), ApiError> {
        let url = self.endpoints.passport(CHECK_STOKEN_PATH);
        self.get_json::<IgnoredAny>(url, self.bbs_headers(Some(credentials))?)
            .await?
            .ensure_ok()
    }

    /// 第 1 步：用游戏二维码的 ticket 调 panda 扫码，换来 passport 二维码的票据。
    pub async fn panda_scan(&self, qr: &LoginQr) -> Result<PassportTicket, ApiError> {
        let url = self.endpoints.panda_scan(qr.game.biz_key);
        let body = json!({
            "passport_app_id": BBS_APP_ID,
            "ticket": qr.ticket,
            "app_id": qr.game.app_id,
            "device": self.device_id,
            "ts": jiff::Timestamp::now().as_second(),
        });
        let data: PandaScanData = self
            .post_json(url, self.bbs_headers(None)?, &body)
            .await?
            .into_data()?;
        parse_passport_url(&data.passport_qr_url)
            .map_err(|e| ApiError::Format(format!("passport_qr_url 不合法：{e}")))
    }

    /// 第 2 步：passport 扫码。返回服务器认定的登录目标应用，确认前要核对。
    pub async fn passport_scan(
        &self,
        ticket: &PassportTicket,
        credentials: &Credentials<'_>,
    ) -> Result<ScannedApp, ApiError> {
        let url = self.endpoints.passport(SCAN_PATH);
        self.post_json(url, self.bbs_headers(Some(credentials))?, &passport_body(ticket))
            .await?
            .into_data()
    }

    /// 第 3 步：确认登录。
    pub async fn passport_confirm(
        &self,
        ticket: &PassportTicket,
        credentials: &Credentials<'_>,
    ) -> Result<(), ApiError> {
        let url = self.endpoints.passport(CONFIRM_PATH);
        self.post_json::<_, IgnoredAny>(url, self.bbs_headers(Some(credentials))?, &passport_body(ticket))
            .await?
            .ensure_ok()
    }
}

fn passport_body(ticket: &PassportTicket) -> serde_json::Value {
    json!({ "ticket": ticket.tk, "token_types": ticket.token_types })
}
```

```rust
//! 绑定账号：米哈游启动器（HoYoPlay）的 passport 扫码登录（设计文档第 6.1 节）。

use mhy_carry_core::account::SecretString;
use reqwest::header::{HeaderMap, HeaderValue, USER_AGENT};
use serde::de::Error as _;
use serde::{Deserialize, Deserializer};
use serde_json::{Value, json};

use crate::client::ApiClient;
use crate::error::ApiError;

const HYP_APP_ID: &str = "ddxf5dufpuyo";
const HYP_CLIENT_TYPE: &str = "3";
const HYP_USER_AGENT: &str = "HYPContainer/1.1.4.133";
const CREATE_PATH: &str = "/account/ma-cn-passport/app/createQRLogin";
const QUERY_PATH: &str = "/account/ma-cn-passport/app/queryQRLoginStatus";
/// `tokens` 里 `token_type` 为 1 的是 stoken。
const STOKEN_TYPE: i64 = 1;

/// 给米游社 App 扫的绑定二维码。
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct BindQr {
    /// 二维码内容。
    pub url: String,
    /// 查询状态用的票据。
    pub ticket: String,
}

#[derive(Debug)]
pub enum BindStatus {
    /// 还没扫。
    Created,
    /// 已扫码，等手机上确认。
    Scanned,
    Confirmed(BoundAccount),
}

#[derive(Debug)]
pub struct BoundAccount {
    pub uid: String,
    pub mid: String,
    pub stoken: SecretString,
}

#[derive(Deserialize)]
struct CreateData {
    url: String,
    ticket: String,
}

#[derive(Deserialize)]
struct QueryData {
    status: String,
    #[serde(default)]
    tokens: Vec<TokenItem>,
    #[serde(default)]
    user_info: Option<UserInfo>,
}

#[derive(Deserialize)]
struct TokenItem {
    #[serde(deserialize_with = "int_or_string")]
    token_type: i64,
    token: String,
}

#[derive(Deserialize)]
struct UserInfo {
    #[serde(deserialize_with = "string_or_int")]
    aid: String,
    mid: String,
}

impl ApiClient {
    fn hyp_headers(&self) -> Result<HeaderMap, ApiError> {
        let mut headers = HeaderMap::new();
        headers.insert("x-rpc-app_id", HeaderValue::from_static(HYP_APP_ID));
        headers.insert("x-rpc-client_type", HeaderValue::from_static(HYP_CLIENT_TYPE));
        headers.insert("x-rpc-device_id", self.device_header()?);
        headers.insert(USER_AGENT, HeaderValue::from_static(HYP_USER_AGENT));
        Ok(headers)
    }

    pub async fn create_bind_qr(&self) -> Result<BindQr, ApiError> {
        let url = self.endpoints.passport(CREATE_PATH);
        let data: CreateData = self
            .post_json(url, self.hyp_headers()?, &json!({}))
            .await?
            .into_data()?;
        Ok(BindQr {
            url: data.url,
            ticket: data.ticket,
        })
    }

    pub async fn query_bind_qr(&self, ticket: &str) -> Result<BindStatus, ApiError> {
        let url = self.endpoints.passport(QUERY_PATH);
        let data: QueryData = self
            .post_json(url, self.hyp_headers()?, &json!({ "ticket": ticket }))
            .await?
            .into_data()?;
        match data.status.as_str() {
            "Created" | "Init" => Ok(BindStatus::Created),
            "Scanned" => Ok(BindStatus::Scanned),
            "Confirmed" => {
                let stoken = data
                    .tokens
                    .into_iter()
                    .find(|t| t.token_type == STOKEN_TYPE)
                    .ok_or_else(|| ApiError::Format("确认后的返回里没有 stoken".to_owned()))?;
                let user = data
                    .user_info
                    .ok_or_else(|| ApiError::Format("确认后的返回里没有 user_info".to_owned()))?;
                Ok(BindStatus::Confirmed(BoundAccount {
                    uid: user.aid,
                    mid: user.mid,
                    stoken: SecretString::from(stoken.token),
                }))
            }
            other => Err(ApiError::Format(format!("未知的二维码状态：{other}"))),
        }
    }
}

fn string_or_int<'de, D: Deserializer<'de>>(deserializer: D) -> Result<String, D::Error> {
    match Value::deserialize(deserializer)? {
        Value::String(s) => Ok(s),
        Value::Number(n) => Ok(n.to_string()),
        _ => Err(D::Error::custom("应为字符串或数字")),
    }
}

fn int_or_string<'de, D: Deserializer<'de>>(deserializer: D) -> Result<i64, D::Error> {
    match Value::deserialize(deserializer)? {
        Value::Number(n) => n.as_i64().ok_or_else(|| D::Error::custom("数字超出范围")),
        Value::String(s) => s.parse().map_err(|_| D::Error::custom("不是整数")),
        _ => Err(D::Error::custom("应为整数或字符串")),
    }
}
```

```rust
//! bind：用米游社 App 扫码绑定账号。

use std::time::Duration;

use mhy_carry_api::{ApiError, BindStatus, retcode};
use mhy_carry_core::account::Account;
use mhy_carry_core::store::AccountStore;
use qrcode::QrCode;
use qrcode::render::unicode::Dense1x2;

use crate::context::Context;
use crate::{CliResult, prompt};

const POLL_INTERVAL: Duration = Duration::from_secs(2);
/// 查询状态没有副作用，网络出错允许重试一次，连续两次就放弃。
const MAX_NETWORK_ERRORS_IN_A_ROW: u32 = 2;

pub async fn run() -> CliResult {
    let ctx = Context::load()?;
    let mut file = ctx.store.load()?;
    if let Some(existing) = file.accounts.first() {
        let question = format!("已经绑定了账号 {}，要换成新账号吗？", existing.masked_uid());
        if !prompt::confirm(&question)? {
            println!("已取消。");
            return Ok(());
        }
    }

    let qr = ctx.api.create_bind_qr().await?;
    println!("请用米游社 App 扫描下面的二维码，并在手机上确认登录：");
    println!("（扫不出来的话，把终端换成深色背景再试）\n");
    println!("{}", render_qr(&qr.url)?);

    let mut announced_scanned = false;
    let mut network_errors = 0;
    loop {
        tokio::time::sleep(POLL_INTERVAL).await;
        match ctx.api.query_bind_qr(&qr.ticket).await {
            Ok(BindStatus::Created) => network_errors = 0,
            Ok(BindStatus::Scanned) => {
                network_errors = 0;
                if !announced_scanned {
                    println!("已扫码，请在手机上确认。");
                    announced_scanned = true;
                }
            }
            Ok(BindStatus::Confirmed(bound)) => {
                let account = Account::new(bound.uid, bound.mid, bound.stoken, jiff::Timestamp::now());
                let masked = account.masked_uid();
                file.accounts = vec![account];
                ctx.store.save(&file)?;
                println!("绑定成功：{masked}");
                println!("凭证已保存（明文）：{}", ctx.store.path().display());
                return Ok(());
            }
            Err(ApiError::Network(_)) if network_errors + 1 < MAX_NETWORK_ERRORS_IN_A_ROW => {
                network_errors += 1;
            }
            Err(error) if error.retcode() == Some(retcode::QR_EXPIRED) => {
                return Err("二维码已过期，请重新运行 mhy-carry-cli bind".into());
            }
            Err(error) => return Err(error.into()),
        }
    }
}

    Ok(code
        .render::<Dense1x2>()
        .dark_color(Dense1x2::Light)
        .light_color(Dense1x2::Dark)
        .build())
}
```

```rust
/// 识别图片里的所有二维码，返回它们的文本。
```

```rust
//! DS2 签名。只有实测发现 passport 接口要求签名时才用（设计文档第 14 节）。

use md5::{Digest, Md5};

const PASSPORT_SALT: &str = "JwYDpKvLj6MrMqqYU6jTKF17KNO2PXoS";

pub fn ds2(body: &str, query: &str, t: i64, r: &str) -> String {
    let raw = format!("salt={PASSPORT_SALT}&t={t}&r={r}&b={body}&q={query}");
    let digest = Md5::digest(raw.as_bytes());
    let hex: String = digest.iter().map(|b| format!("{b:02x}")).collect();
    format!("{t},{r},{hex}")
}

/// 6 个随机字母，随机来源是 UUID v4。
pub fn random_r() -> String {
    const LETTERS: &[u8] = b"abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ";
    uuid::Uuid::new_v4().as_bytes()[..6]
        .iter()
        .map(|b| LETTERS[usize::from(*b) % LETTERS.len()] as char)
        .collect()
}
```

### 任务 20：截图方案实验

**文件：**
- 新建：`spikes/capture-bench/Cargo.toml`
- 新建：`spikes/capture-bench/src/main.rs`

这是一次性实验，代码不进正式 crate，也不跑 CI（workspace 的 `exclude` 已经排除了 `spikes`）。xcap 在 Windows 上有两种截图后端：默认的 GDI（截窗口用 PrintWindow，截屏幕区域用 BitBlt），以及打开 `wgc` feature 后的 Windows.Graphics.Capture。实验测 2 种后端 × 2 种截法（截窗口 / 截窗口所在的屏幕区域），共 4 种组合。

注意：xcap 的 `app_name()` 取的是 exe 文件版本信息里的描述，不是进程名，而且对管理员权限运行的进程可能取不到。所以实验按窗口标题找窗口；M2 按进程名找窗口时要用 `QueryFullProcessImageNameW`。

```rust
//! 截图方案实验。用法：
//!   cargo run --release [--features wgc] -- <窗口标题关键字> <window|region> [秒数] [每秒帧数]

use std::error::Error;
use std::time::{Duration, Instant};

use xcap::image::RgbaImage;
use xcap::{Monitor, Window, XCapResult};

fn main() -> Result<(), Box<dyn Error>> {
    let args: Vec<String> = std::env::args().collect();
    let usage = "用法：capture-bench <窗口标题关键字> <window|region> [秒数] [每秒帧数]";
    let title = args.get(1).ok_or(usage)?;
    let method = args.get(2).map(String::as_str).ok_or(usage)?;
    let seconds: u64 = args.get(3).map(|s| s.parse()).transpose()?.unwrap_or(60);
    let fps: u64 = args.get(4).map(|s| s.parse()).transpose()?.unwrap_or(4);
    let backend = if cfg!(feature = "wgc") { "wgc" } else { "gdi" };

    let window = Window::all()?
        .into_iter()
        .find(|w| {
            w.title().map(|t| t.contains(title.as_str())).unwrap_or(false)
                && !w.is_minimized().unwrap_or(true)
        })
        .ok_or("没找到标题包含该关键字、且没有最小化的窗口")?;
    let monitor = window.current_monitor()?;
    println!(
        "窗口：title={:?} pid={} app_name={:?} 位置=({}, {}) 大小={}x{}",
        window.title()?,
        window.pid()?,
        window.app_name().unwrap_or_default(),
        window.x()?,
        window.y()?,
        window.width()?,
        window.height()?,
    );
    println!(
        "显示器：{:?} {}x{} 缩放={}",
        monitor.name()?,
        monitor.width()?,
        monitor.height()?,
        monitor.scale_factor()?,
    );
    println!("后端={backend} 截法={method} 持续 {seconds} 秒，每秒 {fps} 帧");

    let interval = Duration::from_millis(1000 / fps.max(1));
    let cpu_start = cpu_time::ProcessTime::now();
    let wall_start = Instant::now();
    let (mut frames, mut failures) = (0u32, 0u32);
    let mut capture_total = Duration::ZERO;

    while wall_start.elapsed() < Duration::from_secs(seconds) {
        let started = Instant::now();
        let result = match method {
            "window" => window.capture_image(),
            "region" => capture_window_region(&window, &monitor),
            _ => return Err("截法只能是 window 或 region".into()),
        };
        let took = started.elapsed();
        match result {
            Ok(image) => {
                if frames == 0 {
                    let file = format!("first-{backend}-{method}.png");
                    image.save(&file)?;
                    println!(
                        "第一帧 {}x{}，已保存到 {file}，非黑像素占比 {:.1}%",
                        image.width(),
                        image.height(),
                        non_black_ratio(&image) * 100.0
                    );
                }
                frames += 1;
                capture_total += took;
            }
            Err(e) => {
                failures += 1;
                eprintln!("截图失败：{e}");
            }
        }
        if let Some(rest) = interval.checked_sub(started.elapsed()) {
            std::thread::sleep(rest);
        }
    }

    let cpu = cpu_start.elapsed().as_secs_f64();
    let wall = wall_start.elapsed().as_secs_f64();
    let avg_ms = if frames > 0 {
        capture_total.as_secs_f64() * 1000.0 / f64::from(frames)
    } else {
        0.0
    };
    println!("成功 {frames} 帧，失败 {failures} 次，平均每帧截图 {avg_ms:.1} ms");
    println!("CPU 占用：一个核心的 {:.1}%", cpu / wall * 100.0);
    Ok(())
}

/// 截取窗口所在的屏幕区域（坐标相对于窗口所在的显示器）。
fn capture_window_region(window: &Window, monitor: &Monitor) -> XCapResult<RgbaImage> {
    let x = (window.x()? - monitor.x()?).max(0) as u32;
    let y = (window.y()? - monitor.y()?).max(0) as u32;
    let width = window.width()?.min(monitor.width()?.saturating_sub(x));
    let height = window.height()?.min(monitor.height()?.saturating_sub(y));
    monitor.capture_region(x, y, width, height)
}

/// 亮度高于很暗阈值的像素占比，用来判断是不是截到了黑屏。
fn non_black_ratio(image: &RgbaImage) -> f64 {
    let total = u64::from(image.width()) * u64::from(image.height());
    if total == 0 {
        return 0.0;
    }
    let bright = image
        .pixels()
        .filter(|p| p.0[0] > 16 || p.0[1] > 16 || p.0[2] > 16)
        .count() as f64;
    bright / total as f64
}
```
